# 视觉 QA 与返修

## 何时加载

- 要把 `.srt` / 旁白稿做成 HTML 动画并导出成片，需要配套验收；
- 门禁全绿但你怀疑画面有问题（「看着不对但说不上哪不对」就是本 Skill 的入口症状）；
- 要修一个「代码全对、画面全错」的缺陷。

## 第一原则（先读这一条）

**几何门禁全绿 ≠ 画面正确。**

实测：六组几何门禁全绿之后抽帧目视，发现两处画面在说错话——
「0.06」显示成「0 06」（数值被改），白字画白底（对比度 1.00，文字不可读）。
这两类缺陷不在任何几何检查的覆盖范围内。

同理反过来：**代码路径存在 ≠ 画面里有**。曾出现「函数被调用过、类型检查过、
单测过了，但整层视觉元素一个像素都没渲染出来」。

## 八组门禁

| 组 | 查什么 | 抓什么 |
|---|---|---|
| A1/A2 | 规划建起舞台、门禁无问题 | 结构崩了 |
| A3 | 时间轴覆盖 SRT | **片尾被吞** |
| B | 文字不出安全区 | 越界、遮挡 |
| C | 无空白/爆白帧 | 某一拍没渲染 |
| D | 每拍都有镜内运动 | 静止帧 |
| E | 确定性（同 t 两次一致） | `Math.random` 混进画面 |
| F | MP4 媒体探测 | 分辨率/帧率/时长/**音轨** |
| G | 画面数字守恒 | **数值被改** |

## 高频缺陷与根因（每条都附反例）

### 1. 时间轴锚在累积游标上 → 片尾静默丢失

**症状**：成片比 SRT 短。01 语料 11 拍，成片 69.46s，SRT 结束 73.16s，**片尾 3.70s（约 110 帧）完全消失**。

**根因**：动画的起始时间锚点是「上一拍所有 tween 的最远结束点」减交叠量。那个值天然 ≥ 上拍的 `end`，于是每拍往后拖一个交叠量（0.25s），逐拍线性累积。

**修法**：`at = shot.start - OVERLAP`，**永远锚 SRT 的绝对起点**，不锚累积游标。

**反例（要避免的错误修法）**：把 `tl.set` 拉到片尾来「补时长」——那只补了尾巴，中间的漂移还在。

### 2. 折行按字符数硬切 → 画面凭空多出假数字

**症状**：`1922 年` 被切成 `19` / `22` 两行。画面上真的出现了 SRT 里没有的两个数字。

**根因**：`lines(t, n)` 每 n 字一行，不懂词。

**修法**：断点落在数字/拉丁词内部时，把断点推到词末尾。词字符 = 数字、字母、点（小数点属于数字的一部分，否则 `12.75` 会被切成 `12` / `.75`）。

**关键断言**：断行只该换位置，不该增删字符——`lines(t, n).join("") === t` 对任何输入任何 n 都成立。守恒测试比逐例断言可靠。

### 3. 净化层把标点换成空格 → 数值被改

**症状**：画面上「每度大约 0 09 美元」。

**根因**：画面文案不带标点，实现是把标点全表换成空格，而 `.` 和 `,` 都在表里。

**修法**：数字语境先挖坑再净化。`.` `,`（含两侧空白，旁白常写「0. 06」）和紧跟数字的 `%` 属于数值本身，占位成**私用区码位**（如 U+E000），净化完按原字符还原。

**为什么占位符选私用区**：ASCII 标点表盖 0x21–0x7E、CJK 标点表盖 0xA1–0xFF65，两段都盖不住 U+E000。

**反例**：在检测函数里「把 `.` 替换回去再判断」——检测正则本身就含 `.`，会把 `0.06` 判成「含标点」。占位符要**在两个函数里用同一个**。

### 4. 反白专用色当墨色用 → 白字画白底

**症状**：整幅接近全白，文字几乎不可见。

**根因**：色彩 token 的语义在不同风格下不同。`cream` 是**反白专用**——三套风格里都是浅色（浅米 / 纯白），语义是「压在深色块上的字」。某版式把横梁、支点、文字全用 `cream`，而底也是纸白亮底。

**修法**：画在纸上的前景一律用 `ink`（三套风格里都是亮底上的深色）。反白只在**明确压在深色块上**时用。

**门禁**：按实际渲染色算 WCAG 相对亮度差，逐风格断言「文字压纸白底 ≥ 3.0」。

**排除元信息要有依据，不能靠数字形状瞎猜**：拍号角标按**前缀**判（`BEAT 04`/`FIG.07`），坐标轴刻度按「整串纯数字且不在 SRT 数字集」判。

### 5. 年份被当成度量值 → 叙事开场配数据图

**症状**：纯叙事的第一句「1915 年 5 月，一个周末的下午…」被路由到坐标柱版式，把年份画成柱高。属**错误隐喻**。

**根因**：数字抽取有三层正则（百分比 / 带单位 / 中文）+ 一层兜底。纯「1915 年」三层都没命中，落到兜底被判成度量值，于是版式路由选了图表。

**修法**：兜底层加后视否定 `(?!\d{3,}\s*年)`——四位数 + 年是**历法坐标**不是度量值。只挡 1000–2999（人类有记载的年份全在这个区间），不误伤「3000 吨」「1200 毫秒」。

### 6. 版式越界的三个真实数值

- **竖排列掉出画面**：只卡了 `size ≤ 92` 没卡**列总高**。9 字 × 62 × 1.16 = 648，末行基线落到 673，出下边 93px。改为按列高反推行距并限制最大字数。
- **巨号数字单位冲出右边界**：字号只按数字部分算（1000px 满宽），单位贴在右缘再 +40px → 出右 72px。另一个错：公式把半宽算了两遍（数字以 x=640 居中时右缘已是 `x + len*size/2`）。**数字+单位要作为一个整体算宽度。**
- **两行标题出下边**：SVG `<text>` 不自动折行。

## 关键测量常量（别靠估）

| 量 | 值 |
|---|---|
| CJK `getBoundingClientRect` 高 | **≈ 1.78em**（46px 字号实测 82px，含下伸部） |
| CJK 字宽 | ≈ 1em |
| 拉丁/数字字宽 | ≈ 0.55em |
| 等宽 advance | ≈ 0.6em（0.62em 兜底） |

按「1.0–1.3em」估 CJK 行高是错的——本项目因此修了两版才把两行标题收进版心。

**测位置用 `getBoundingClientRect` 不用 `getBBox`**：后者不含祖先 transform，但含自身 transform，GSAP 的入场位移会被算进去，测到的是动画中途的位置。

**只在稳定构图时测**：取 `start + 2.0s`（多数入场 <1.5s），入场期间的坐标不代表成片。

**只测当前可见的那一层**：舞台把所有拍的图层挂在同一个 SVG 里靠 opacity 切换，对整个 SVG 查询会把每一拍都量一遍，报出来的「越界」其实来自别的拍。

## 门禁自身的三个坑

1. **逐帧取样必须显式重画**。`seek()` 只推时间轴置脏，真正重画在 rAF 循环里；测试为省性能关掉自动渲染时会读到旧帧，「镜内有运动」恒为 0。
2. **`frame` 必须是 `t` 的函数**。后期颗粒按帧号取（`Math.imul(frame, 37)`），用「调用计数器」当 frame 会让两次采样落在不同帧上，误报不确定。
3. **超时按片长放宽**。导出整片是一次阻塞调用，208s 片子（4998 帧）在默认 120s 超时处被掐断。用 `max(300000, ceil(duration * 40000) + 120000)`，并 try/catch 包住——超时只该让那一项失败，不该整个跑挂。

## 门禁抓不住的清单（抽帧目视才行）

- 数字被改值（用内容比对门禁补，不要靠目视）
- 文字不可读 / 对比度不足（用 WCAG 门禁补）
- 版式与语义不匹配（**错误隐喻**）——坐标柱画年份、照片配错语料
- 构图偏空、留白失衡
- 「像逐页 PPT」的整体观感

## 返修五步（每个问题都走）

**证据 → 根因 → 对应模块 → 修改 → 回归测试**。

回归测试必须**双向验证过**：改完跑绿不算数，要 `git stash` 掉修复、确认测试变红，再恢复。没验证过的测试等于没加。

## 复现命令

```bash
# 全套（含导出，约 20 分钟）
node tools/phase10-qa.mjs
# 只跑几何+内容门禁（约 3 分钟）
node tools/phase10-qa.mjs --no-export
# 单题材
node tools/phase10-qa.mjs --only 03
# 接触印相
ffmpeg -i 01.mp4 -vf "select='not(mod(n\,160))',scale=426:240,tile=5x3" -frames:v 1 sheet.png
```

## 退出条件

- 固定测试集**每个题材**都能完整导出，不是只跑通过的那个；
- 每个严重问题有明确处理状态（修好 / 有意保留并写进「尚存缺陷」，不许含糊）；
- **不得用只展示最好看的单个镜头替代全片验收。**
