# 图像代码画法 · 速查总览

**这份文档解决什么问题**：要画一个图形/图表/画面时，先决定「用什么画」，再查「怎么画」，
最后避开已知的坑。七份专题手册 + 15 个可双击运行的片段是配套的。

**怎么用**：
1. 从下面的**选型决策树**定技术路线（30 秒内能定）
2. 翻对应专题手册找骨架代码
3. 打开对应片段文件看实际效果
4. 动手前扫一眼**反模式清单**

来源：Agent Reach / Jina Reader 抓取的 MDN、Sara Soueidan、CSS-Tricks、Emil Kowalski、
GSAP 官方、The Book of Shaders、D3/Chart.js/ECharts、three.js manual、
Ciechanowski、Red Blob Games 等权威源，2026-10。

## 一、选型决策树：要画 X，用什么画

### 第一问：这是「内容」还是「装饰」？

| 情形 | 选谁 | 理由 |
|---|---|---|
| 图形是**画面主角**、需要精确版式控制 | **SVG** | 矢量、可 CSS 控制样式、每个几何元素可独立寻址（能单独做动画） |
| 图形是**背景/氛围**、要大量动态像素 | **Canvas 2D** 或 **WebGL** | 像素级控制、粒子/噪声/滤镜性能强 |
| 图形要**参与布局**、和文字流一起排 | **纯 CSS** | 不需要额外 DOM 层，响应式自动 |
| 要**真 3D 透视**、光照、材质 | **Three.js** | 场景图 + 光照 + 材质系统现成 |
| 要**程序化图形**（噪声、距离场、液态） | **GLSL 着色器** | 按像素算，表达力最强 |

### 第二问：数据可视化怎么选？

| 需求 | 选谁 | 判据 |
|---|---|---|
| 要**极致控制版式**、图表要给文字让位、要逐帧渲染 | **手绘 SVG**（自写映射函数） | 用 10 行的 `scaleLinear` 替代品就够，见 `05-图表代码画法.md` V04 |
| 要**享受 D3 的数学**但不要它的 DOM 模型 | **d3-scale + d3-shape 单独引入** | 只取 `domain/range/nice/ticks` 与 `line/area/arc/pie/stack` 生成 `d` 字符串，自己渲染 |
| 要**快速出标准图** | **Chart.js** | 配置即出图，Canvas 渲染 |
| 要**复杂交互 / 大数据量 / 中文生态** | **ECharts** | `renderer: 'svg'` 可切矢量输出 |
| 图是**数据驱动的**但没有数据 | **什么都别画** | 无数据画图 = 让画面声称一个不存在的形状 |

### 第三问：动效怎么做？

| 需求 | 选谁 | 判据 |
|---|---|---|
| 状态切换（hover / 展开 / 主题） | **CSS transition** | 天然可中断，走合成器 |
| 循环播放的装饰动画 | **CSS @keyframes** | 无需 JS |
| 复杂时间线（多元素编排、错峰入场） | **GSAP timeline** | position 参数能精确定位（`"<"` / `"+="` / 标签） |
| **逐帧可重复渲染**（导出视频、视觉回归） | **GSAP `paused:true` + 手动 `tl.time(t)`** | 时间必须由外部给定，不能用墙钟 |
| 一两个元素的小位移 | **WAAPI** | 走合成器，有 `pause/seek` |

## 四、反模式清单（动手前扫一眼）

### SVG
- **嵌套 `<svg>` 不写 `x`/`y`** → 永远画在父级原点。这是 srt-film 里 13 个图形全挤到左上角的真凶。
- **多个实例共用同一个 `id`** → 渐变/pattern/clipPath/mask 的 `url(#id)` 会全部指向第一个定义。**解决办法：id 里带上实例标识。** srt-film 的装饰层点阵 pattern 就是这么修的。
- **`clipPath` 内容有限制** → 不是任意内容都能放，某些元素无效。
- 想用 CSS 动画去动那些**不是 CSS 属性的 SVG 表现属性**（如 `points`）→ 动不了。

### Canvas
- **`save()` / `restore()` 不配对** → 变换与样式泄漏到后续所有绘制，表现是「越画越歪」。
- **变换顺序搞错** → `translate` 后再 `scale` 与 `scale` 后再 `translate` 结果完全不同。
- **不做 DPR 缩放** → 高清屏上发虚。正确写法：`canvas.width = cssW * dpr` + `ctx.scale(dpr, dpr)`。
- **每帧 `getImageData`** → 触发 CPU-GPU 同步读回，帧率暴跌。
- **`setInterval` 做动画** → 与刷新率不同步，且后台标签页不会停。
- **奇宽描边不取 `x.5`** → 线发虚（像素对齐规则）。

### CSS
- **`clip-path` 在不同形状之间做动画** → 无法插值，直接跳变。只有**同形状同点数**才平滑。
- **一个色标挂三个位置** → 整条渐变声明被丢弃（`red 0 20% 40%` 是错的，每个色标最多两个位置）。
- **`filter` / `backdrop-filter` 滥用** → 每次都要离屏合成，移动端掉帧。`mix-blend-mode` 还会强制建立堆叠上下文。

### 动效
- **`scale(0)` 入场** → 从虚无开始，观感生硬。留一点体积（如 `0.95`）。
- **给高频操作加动画**（键盘、反复触发的交互）→ 拖慢熟练用户。
- **不处理 `prefers-reduced-motion`** → 前庭功能障碍用户会被动效伤到。
- **用 `top`/`left` 做位移动画** → 触发 layout，要改用 `transform`。
- **时长过长** → 超过 ~500ms 就感觉「卡」。

### 确定性渲染（做视频/逐帧导出必看）
- **用 `Math.random()` / `Date.now()` 当时间源** → 每次渲染结果不同，无法做帧对齐与回归测试。
- **用 `getDelta()` 累积推进状态** → 浮点误差随帧数累积，跑两遍结果有微小差异。要**绝对时间**。
- **依赖 CSS 动画做逐帧截图** → 无法精确 seek 到第 t 帧（负 `animation-delay` 只是近似）。
- **开着 HMR / 热重载做长时间渲染** → 文件一改，页面刷新，导出中断。要切生产构建。
- **把 `yoyo`+`repeat` 的环境动效直接挂到整拍图层** → 实际时长是 2× duration，会把总时间线撑爆（srt-film 从 61s 被撑到 136s 就是这么来的）。

### 图表
- **y 轴忘了翻转** → SVG 的 y 向下增长，数据 y 向上增长。
- **刻度不做 nice numbers** → 出现 `0 / 33.33 / 66.67` 这种别扭刻度。
- **几何没拆成可寻址元素** → 想做「线条生长」「柱子生长」时无从下手。

### 3D / 着色器
- **忘了修宽高比** → `st` 直接把画面拉伸变形。要乘 `resolution.y / resolution.x`。
- **`random` 不先 `floor` 量化** → 同一格内的像素拿到不同随机值，出噪声不是出图案。
- **每帧全量重绘静态内容** → 用按需渲染（`renderRequested` 标志）。
