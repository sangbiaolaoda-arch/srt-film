Canvas 高清屏适配

这个片段演示什么：同一个圆、同一段文字，不做 devicePixelRatio 缩放 vs 做了 DPR 缩放，在高清屏上的清晰度差别。拖动滑块把两边一起放大，边缘差异立刻看得出来。

并排对照

你的屏幕 devicePixelRatio = 1。若为 1（普通屏），把浏览器缩放调到 150%+ 或换到高清屏，差异才明显。

2.0×
核心代码 
const CSSW = 300, CSSH = 200;

// ✗ 不处理：位图 = CSS 尺寸。高清屏上每个 CSS 像素要铺 dpr 个设备像素 → 放大失真
canvas.width = CSSW;
canvas.height = CSSH;

// ✓ 处理：位图放大 dpr 倍，再把绘图坐标系 scale 回去
const dpr = window.devicePixelRatio || 1;
canvas.width  = Math.round(CSSW * dpr);   // 关键点：位图分辨率 = CSS 尺寸 × dpr
canvas.height = Math.round(CSSH * dpr);
canvas.style.width  = CSSW + "px";        // 关键点：显示尺寸仍是 CSS 像素
canvas.style.height = CSSH + "px";
const ctx = canvas.getContext("2d");
ctx.scale(dpr, dpr);                      // 关键点：之后照常用 CSS 像素坐标画

// 一句话可复用版
function setupHiDPI(canvas, cssW, cssH) {
  const dpr = window.devicePixelRatio || 1;
  canvas.width  = Math.round(cssW * dpr);
  canvas.height = Math.round(cssH * dpr);
  canvas.style.width  = cssW + "px";
  canvas.style.height = cssH + "px";
  const ctx = canvas.getContext("2d");
  ctx.scale(dpr, dpr);
  return ctx;
}

// 易错点：改 canvas.width/height 会清空画布并重置所有 context 状态，
// 所以 ctx.scale(dpr, dpr) 必须在设置尺寸「之后」调用，且 resize 时要重新执行。
