Canvas 合成模式对照

这个片段演示什么：同一组「蓝色方块（目标 destination）+ 红色圆（源 source）」，在 26 种 globalCompositeOperation 下叠加出的不同结果。灰白棋盘格代表透明区域。

26 种叠加取值一览

每格：蓝方块 = 画布上已有内容（目标），红圆 = 正在画的新内容（源）。看红圆和蓝方块怎么互相作用。

三种最常用效果该用哪个

想要的效果用哪个取值原理
挖空 / 橡皮擦（把已有内容删掉一块）destination-out用源的形状去减目标，重叠处目标被清成透明
发光 / 叠加变亮lighter源与目标的颜色、alpha 相加，越叠越亮
只在已有图形内部上色（高光、花纹、遮罩填充）source-atop源只画在目标不透明的地方，不超出已有轮廓
反相遮罩（保留重叠处，形状取自目标）destination-in只留下目标与源重叠的部分
正片叠底阴影 / 压暗multiply逐通道相乘，结果只会更暗
整体重画（等价于先清屏再画）copy只显示源，画布其余位置被清空

要点：source-* 取形状的「源」，destination-* 取形状的「目标」，atop = 只在目标不透明处、in = 只留重叠、out = 只留不重叠、xor = 只留不重叠两侧。

核心代码 
const OPS = [
  "source-over", "source-in", "source-out", "source-atop",
  "destination-over", "destination-in", "destination-out", "destination-atop",
  "lighter", "copy", "xor",
  "multiply", "screen", "overlay", "darken", "lighten",
  "color-dodge", "color-burn", "hard-light", "soft-light",
  "difference", "exclusion", "hue", "saturation", "color", "luminosity"
];

const CELL = 110, COLS = 6;
const canvas = document.getElementById("grid");
const ctx = canvas.getContext("2d");

// 关键点：每个格子单独用一个离屏 canvas。
// 若全画在一张画布上，copy / destination-* 会波及已经画好的其它格子。
const off = document.createElement("canvas");
off.width = off.height = CELL;
const octx = off.getContext("2d");

OPS.forEach((op, i) => {
  const cx = (i % COLS) * CELL, cy = Math.floor(i / COLS) * CELL;

  // 1) 目标：蓝方块（先画，用默认 source-over）
  octx.globalCompositeOperation = "source-over";
  octx.fillStyle = "rgba(0,120,255,0.9)";
  octx.fillRect(22, 36, 60, 60);

  // 2) 源：红圆，用被测的合成模式叠上去
  octx.globalCompositeOperation = op;
  octx.fillStyle = "rgba(255,60,60,0.9)";
  octx.beginPath();
  octx.arc(64, 72, 28, 0, Math.PI * 2);
  octx.fill();

  octx.globalCompositeOperation = "source-over";
  ctx.drawImage(off, cx, cy);   // 贴回主画布

  // 3) 标签
  ctx.fillStyle = "#1c1b18";
  ctx.font = "10px ui-monospace, Consolas, monospace";
  ctx.textAlign = "left";
  ctx.textBaseline = "top";
  ctx.fillText(op, cx + 9, cy + 8);
});

// 常用写法
ctx.globalCompositeOperation = "destination-out";  // 挖空
ctx.globalCompositeOperation = "lighter";          // 发光
ctx.globalCompositeOperation = "source-atop";      // 只在已有图形内上色
