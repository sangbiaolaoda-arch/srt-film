描边生长动画

这个片段演示什么：用 stroke-dasharray / stroke-dashoffset 让线条从起点长到终点，标出长度怎么算、动画公式怎么写，并给出「量长度」与「归一化」两种做法。

1. 原理与公式

① 把整条路径包成「一段实线 + 等长空白」：dasharray = L L（简写 L）
② 初态把实线藏进空白里：dashoffset = L → 看不见
③ 末态让实线全露出：dashoffset = 0 → 画满
④ L = getTotalLength() 实测值；或用属性 pathLength="1" 归一化成 1，省去量长

dashoffset 相当于把虚线的起点沿路径往后退：offset 等于一个实线长度时，露出的正好全是空白。

2. 归一化写法：pathLength="1"（路径多长都通用）

3. 实测写法：JS 量长度后驱动动画

下面这条路径的实际长度由 getTotalLength() 量出：… 用户单位，然后把它当作 dasharray / dashoffset 的初值。

4. 端点细节：linecap 影响生长两端的样子

stroke-linecap: round 让线头是圆的，生长动画看起来更像笔刷；butt（默认）是平头，起步会更「硬」。

核心代码 
<!-- 关键点：归一化写法 —— pathLength="1" 省去量长，任何路径都通用 -->
<svg width="320" height="110" viewBox="0 0 320 110">
  <path class="grow" pathLength="1"
        d="M 20 60 C 80 5, 150 115, 210 60 S 290 15, 305 60"
        fill="none" stroke="#c8401f" stroke-width="5" stroke-linecap="round"/>
</svg>
<style>
  /* 关键点：dasharray=1 把路径包成「实线+等长空白」；dashoffset 1→0 即生长 */
  .grow{ stroke-dasharray:1; stroke-dashoffset:1;
         animation:draw 2s ease forwards; }
  @keyframes draw{ to{ stroke-dashoffset:0; } }
</style>

<!-- 关键点：实测写法 —— 不写 pathLength，用 JS 取真实长度 -->
<script>
  const p = document.getElementById('curve');
  const L = p.getTotalLength();            // ④ 量出真实长度
  p.style.strokeDasharray  = L;            // ① dasharray = L
  p.style.strokeDashoffset = L;            // ② 初态藏起来
  requestAnimationFrame(() => {
    p.style.transition = 'stroke-dashoffset 2s ease';
    p.style.strokeDashoffset = 0;          // ③ 末态画满
  });
</script>
