viewBox 与坐标系

这个片段演示什么：同一个图形在三种 viewBox 下被“放大 / 平移”的不同呈现，preserveAspectRatio 里 meet 与 slice 的差别，以及嵌套 <svg> 不写 x/y 会掉到父级原点的陷阱。

1. 一张图，三种 viewBox

同一个 rect + circle，外层尺寸都写 200×150，只改 viewBox。

viewBox="0 0 200 150"　1:1
viewBox="0 0 100 75"　放大 2×
viewBox="25 25 100 75"　平移 + 放大

公式：缩放比 = 视口宽 ÷ viewBox 宽；非零 min-x/min-y 再补一次 translate(-minx -miny)。

2. preserveAspectRatio：meet 与 slice

视口 260×130、viewBox 是正方形 130×130 —— 宽高比不同时看它怎么处理。

xMidYMid meet　完整可见
xMidYMid slice　铺满裁切
none　非等比拉伸（变形）

3. 嵌套 <svg> 不写 x/y 会落在父级原点

父级都是 300×200，虚线框标出“想让小红圆出现的位置”。内层 svg 只有 80×80。

✅ 写了 x="180" y="100"
❌ 省掉 x/y → 掉到 (0,0)

要点：内层 x/y/width/height 用父级用户单位，内层内容用自己的 viewBox 单位；内层视口默认 overflow: hidden，想留白只能靠 x/y 位移，不能靠 margin。

核心代码 
<!-- 关键点：视口 200×150，三种 viewBox 只改第一个与后两个参数 -->
<svg width="200" height="150" viewBox="0 0 200 150">
  <circle cx="100" cy="75" r="50" fill="#c8401f"/>
</svg>

<svg width="200" height="150" viewBox="0 0 100 75">        <!-- 放大 2× -->
<svg width="200" height="150" viewBox="25 25 100 75">     <!-- 平移+放大 -->

<!-- 关键点：宽高比不同时，meet 完整装下 / slice 铺满裁切 / none 拉伸变形 -->
<svg width="260" height="130" viewBox="0 0 130 130"
     preserveAspectRatio="xMidYMid meet"> ... </svg>

<!-- 关键点：嵌套 svg 的 x/y 默认是 0，不写就贴在父级原点 -->
<svg width="300" height="200" viewBox="0 0 300 200">
  <svg x="180" y="100" width="80" height="80" viewBox="0 0 10 10">
    <circle cx="5" cy="5" r="5" fill="#c8401f"/>
  </svg>
</svg>
