clip-path 剪出任意形状

这个片段演示什么：五种基本形状 inset / circle / ellipse / polygon / path 的语法，几个现成的多边形（六边形、五角星、八边形），以及动画「只能同形状同点数之间插值」这条规则。

1. 五种基本形状

inset 用空格分隔（无逗号，序是上右下左）；circle / ellipse 用 at x y 定圆心；polygon 用逗号分组；path 用绝对 px 坐标、不随元素尺寸自适应。

inset(14px 26px 32px 42px)

inset(14px 26px round 16px)

circle(55px at 50% 50%)

ellipse(80px 46px at 50% 50%)

polygon(50% 0%, 100% 100%, 0% 100%)

path("M 10 12 L 172 24 L 122 114 L 34 92 Z")

2. 现成形状：六边形 / 五角星 / 八边形

把元素想成坐标系（左上 0%,0% → 右下 100%,100%），按顺时针依次写下每个顶点的 x y 即可。想算术就用 calc()。

3. 动画规则：只能同形状、同点数插值

浏览器要「逐点连线」做补间，所以形状类型或点数不一致时直接跳变、没有过渡。

✅ polygon(3 点) → polygon(3 点)：平滑变形

✅ circle → circle（改半径）：平滑缩放

❌ polygon ↔ circle：类型不同 → 直接跳

❌ polygon(3 点) ↔ polygon(4 点)：点数不同 → 直接跳

想让「三角变圆」有动画：保持点数不变只改坐标值；或改用两个元素叠加做透明度交叉淡入，或改用 mask + 径向渐变。另外 clip-path: url(#id) 引用型的裁剪不能用 CSS 过渡，要动就在 <clipPath> 内用 SMIL。

核心代码 
/* 关键点：五种基本形状的语法差异 —— inset 无逗号，其余逗号分组 */
.inset   { clip-path: inset(14px 26px 32px 42px); }          /* 上 右 下 左 */
.inset-r { clip-path: inset(14px 26px round 16px); }         /* round 加圆角 */
.circle  { clip-path: circle(55px at 50% 50%); }
.ellipse { clip-path: ellipse(80px 46px at 50% 50%); }
.polygon { clip-path: polygon(50% 0%, 100% 100%, 0% 100%); }
.path    { clip-path: path("M 10 12 L 172 24 L 122 114 L 34 92 Z"); } /* 只能 px */

/* 关键点：现成多边形 —— 顺时针依次写顶点 */
.hexagon { clip-path: polygon(25% 0%, 75% 0%, 100% 50%,
                              75% 100%, 25% 100%, 0% 50%); }
.star    { clip-path: polygon(50% 0%, 61% 35%, 98% 35%, 68% 57%, 79% 91%,
                              50% 70%, 21% 91%, 32% 57%, 2% 35%, 39% 35%); }

/* 关键点：能插值 —— 同形状、同点数，逐点连线补间 */
@keyframes morph {
  0%, 100% { clip-path: polygon(50% 5%, 0% 100%, 100% 100%); }
  50%      { clip-path: polygon(50% 38%, 6% 100%, 94% 100%); }  /* 还是 3 点 */ }

/* 关键点：不能插值 —— 类型不同（polygon↔circle）或点数不同 → 直接跳 */
@keyframes bad {
  0%, 49%   { clip-path: polygon(50% 0%, 100% 100%, 0% 100%); }
  50%, 100% { clip-path: circle(46% at 50% 50%); } }
