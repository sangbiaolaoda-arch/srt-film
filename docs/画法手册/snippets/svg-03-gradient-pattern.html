渐变与 pattern

这个片段演示什么：线性/径向渐变的方向与焦点、spreadMethod 三种填充方式、gradientUnits 两种坐标系的对照、pattern 瓷砖，以及两个实例共用同一个 id 时第二个被第一个定义污染的坑。

1. linearGradient：方向由 x1/y1 → x2/y2 决定

默认是水平（左→右）；把两点设成 x1=x2、y1=0 y2=1 就是垂直。

上：水平　下：垂直
中段 stop-opacity:0 → 中间透明

2. radialGradient 与 spreadMethod

径向用「结束圆 cx/cy/r」+「焦点 fx/fy」两个点定义。渐变走完圆之后怎么继续，由 spreadMethod 决定。

焦点偏移的球形高光
pad（默认）　repeat　reflect

3. gradientUnits：跟着元素走 vs 钉在画布上

同样一块渐变，套在「大矩形」和「小矩形」上，两种坐标系给出的结果完全不同。

objectBoundingBox：两个都从各自中心发光
userSpaceOnUse：小矩形只截到渐变的边缘

4. pattern：瓷砖平铺

圆点瓷砖
45° 斜纹瓷砖

5. 坑：两个渐变实例共用同一个 id

下面两个 <svg> 各自定义了 id="conflict" 的渐变，但整个页面是同一份文档，url(#conflict) 只会解析到文档中第一次出现的那个定义。

实例 1：红→蓝（期望）
实例 2：本该绿→黄，却仍渲染成红→蓝 ❌
修复：唯一 id → 绿→黄 ✅
组件化复用 SVG 时（图标、列表渲染多份），务必给 id 加实例唯一后缀，或用 CSS 变量 / currentColor 传色，别让多份实例抢同一个 id。
核心代码 
<!-- 关键点：linearGradient 方向由两点决定；默认水平，改成 x1=0 x2=0 y1=0 y2=1 即垂直 -->
<linearGradient id="gV" x1="0" x2="0" y1="0" y2="1">
  <stop offset="0%" stop-color="#c8401f"/>
  <stop offset="50%" stop-color="#1c1b18" stop-opacity="0"/>
  <stop offset="100%" stop-color="#2b6cb0"/>
</linearGradient>

<!-- 关键点：径向 = 结束圆(cx cy r) + 焦点(fx fy)；spreadMethod 决定走完圆之后怎么续 -->
<radialGradient id="sRepeat" cx="0.5" cy="0.5" r="0.4" fx="0.75" fy="0.75"
                spreadMethod="repeat"> ... </radialGradient>
<!-- pad 末端色填满 / repeat 跳回起点 / reflect 镜像往返 -->

<!-- 关键点：objectBoundingBox 用 0~1 比例贴合各自元素；userSpaceOnUse 钉在画布固定坐标 -->
<radialGradient id="uUser" cx="70" cy="70" r="60" gradientUnits="userSpaceOnUse"> ... </radialGradient>

<!-- 关键点：pattern 把内容当瓷砖，用 width/height 平铺 -->
<pattern id="pDots" width="24" height="24" patternUnits="userSpaceOnUse">
  <circle cx="12" cy="12" r="4" fill="#c8401f"/>
</pattern>
<rect width="220" height="120" fill="url(#pDots)"/>

<!-- 关键点：id 必须文档级唯一，重复 id 时 url(#x) 只认第一个定义 -->
<linearGradient id="grad-{{uid}}"> ... </linearGradient>
<rect fill="url(#grad-{{uid}})" />
