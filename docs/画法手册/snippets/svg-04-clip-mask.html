clipPath 与 mask

这个片段演示什么：同一块内容分别被 clipPath「硬边裁掉」和被 mask「软边遮罩」的差别，clipPathUnits 两种坐标系，以及 mask 的 luminance 与 alpha 两种模式。

1. 硬裁剪 vs 软遮罩

同一张红→蓝渐变方块：左图被圆形 clipPath 剪掉外部（边缘是硬的），右图被径向渐变 mask 遮住（边缘是柔的）。

clipPath：圆外被剪掉，边缘锐利
mask：亮度决定可见度，边缘羽化

2. clipPathUnits：自动贴合 vs 钉在画布

同样的「圆形裁剪」，套在大矩形和小矩形上，两种坐标系结果完全不同。

objectBoundingBox：两个都被裁成贴着各自尺寸的圆
userSpaceOnUse：小矩形落在裁剪区外，整块消失

3. mask 的 luminance 与 alpha 两种模式

用同一张「白→黑」渐变当遮罩，只切换 mask-type：luminance 按亮度做透明，alpha 只认 alpha 通道（白与黑都不透明 → 没有渐隐）。

luminance：右侧渐隐（白端显示）
alpha：颜色无关紧要，白/黑都全不透明 → 没有渐隐

想让 alpha 模式也有渐隐，遮罩里就要用 stop-opacity 从 1 到 0 的渐变——那时 alpha 才有变化。另外：<clipPath> 里不能放 <g> 分组，一放整个裁剪就失效。

核心代码 
<!-- 关键点：clipPath 放矢量路径 → 硬边裁剪（路径外透明） -->
<clipPath id="circleClip">
  <circle cx="110" cy="75" r="58"/>
</clipPath>
<rect fill="url(#paint)" clip-path="url(#circleClip)"/>

<!-- 关键点：mask 放图像/渐变 → 按亮度做软过渡 -->
<radialGradient id="softCircle">
  <stop offset="0%" stop-color="#fff"/>
  <stop offset="70%" stop-color="#fff"/>
  <stop offset="100%" stop-color="#000"/>
</radialGradient>
<mask id="circleMask" maskUnits="userSpaceOnUse" x="0" y="0" width="220" height="150">
  <rect width="220" height="150" fill="url(#softCircle)"/>
</mask>
<rect fill="url(#paint)" mask="url(#circleMask)"/>

<!-- 关键点：objectBoundingBox 用 0~1 分数坐标，自动贴合各元素尺寸 -->
<clipPath id="cpObb" clipPathUnits="objectBoundingBox">
  <circle cx="0.5" cy="0.5" r="0.5"/>
</clipPath>

<!-- 关键点：mask-type 决定按亮度还是按 alpha 取可见度 -->
<mask id="mFade" style="mask-type:luminance"> ... </mask>   <!-- 白显黑隐 -->
<mask id="mAlpha" style="mask-type:alpha"> ... </mask>       <!-- 只认 alpha -->
