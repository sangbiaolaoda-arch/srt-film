渐变当画笔

这个片段演示什么：把 background 渐变当像素用——硬中断造锐利边界、repeating 造条纹、多层叠加造棋盘格、conic 造饼图、再配合 mask 挖出甜甜圈。

1. 硬中断：锐利边界（最核心技巧）

把两个色标放在同一个位置，过渡宽度归零，就得到一条硬边；左图硬、右图是默认的模糊插值。

#000 0 50%, #f1efe9 50% 100%　硬边

#000 0%, #f1efe9 100%　默认模糊过渡

2. repeating 条纹

一个重复周期 = 最后一个色标位置 − 第一个色标位置（下面都是 24px − 0 = 24px）。

repeating-linear-gradient(0deg…)

repeating-linear-gradient(45deg…)

3. 多层叠加：棋盘格

两层 45° 硬中断渐变各画一组对角方块，用 background-position 错开半格后交叉，正好拼成棋盘。

两层 linear-gradient(45deg) + background-size:40px

4. conic-gradient 饼图 / 进度环

conic 三段硬中断：40% / 30% / 30%

饼图 + mask 径向渐变挖空中心 → 甜甜圈/进度环

5. 色带：多段硬中断拼彩虹

每个 stop 最多跟两个位置。写成 yellow 0 40% 60% 这种三个位置是非法的，会整条声明失效。

linear-gradient(90deg) 五段各占 20%

核心代码 
/* 关键点：两个色标放同一位置 = 硬中断，边界锐利 */
background: linear-gradient(90deg, #1c1b18 0 50%, #f1efe9 50% 100%);

/* 关键点：repeating 造条纹，一个周期 = 末色标位置 − 首色标位置 */
background: repeating-linear-gradient(0deg, #1c1b18 0 12px, #f1efe9 12px 24px);

/* 关键点：两层 45° 对角方块错开半格 → 棋盘格 */
.checker {
  background-color:#fff;
  background-image:
    linear-gradient(45deg, #1c1b18 25%, transparent 25% 75%, #1c1b18 75%),
    linear-gradient(45deg, #1c1b18 25%, transparent 25% 75%, #1c1b18 75%);
  background-size:40px 40px;
  background-position:0 0, 20px 20px; }

/* 关键点：conic-gradient 每段一个硬中断区间 → 饼图 */
.pie { border-radius:50%; background: conic-gradient(
  #c8401f 0 40%, #f1c40f 40% 70%, #2b6cb0 70% 100%); }

/* 关键点：饼图 + mask 径向渐变挖空中心 → 甜甜圈 */
.donut {
  border-radius:50%;
  background: conic-gradient(#c8401f 0 65%, #ecf0f1 65% 100%);
  mask: radial-gradient(circle, transparent 0 44%, #000 45%);
  -webkit-mask: radial-gradient(circle, transparent 0 44%, #000 45%); }

/* 关键点：色带每段用「色 起 止」两个位置，别写三个位置 */
background: linear-gradient(90deg,
  #c8401f 0 20%, #e67e22 20% 40%, #f1c40f 40% 60%, #1abc9c 60% 80%, #2b6cb0 80% 100%);
