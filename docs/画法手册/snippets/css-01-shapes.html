纯 CSS 形状集

这个片段演示什么：不用 SVG、不引图片，只用盒模型（border / border-radius / transform）就能画出的常见形状，每个都标注了用到的属性。

三角形原理：宽高为 0 + 四条粗边框

一个 width:0; height:0 的元素配上等宽边框时，四条边各自收成一个三角形，在中心交汇。要哪个方向的三角，就只给对应那条边上色，其余三边设 transparent。

  • 上边框 = 尖朝下（红）
  • 右边框 = 尖朝左（蓝）
  • 下边框 = 尖朝上（绿）
  • 左边框 = 尖朝右（黄）

形状一览

每个卡片下方标注所用属性。

核心代码 
/* 关键点：四方向三角形 —— 宽高为 0，只给一条边上色，其余 transparent */
.tri-up    { width:0; height:0;
  border-left:45px solid transparent;
  border-right:45px solid transparent;
  border-bottom:70px solid #c8401f; }   /* 尖朝上 → 涂下边框 */

/* 关键点：圆形 = 等宽高 + 50% 圆角；椭圆 = 宽高不等 + 50% 圆角 */
.circle { width:90px; height:90px; border-radius:50%; }
.oval   { width:130px; height:80px; border-radius:50%; }

/* 关键点：梯形 = 下边框上色 + 两侧透明斜边 */
.trapezoid { width:110px; height:0;
  border-bottom:65px solid #1abc9c;
  border-left:28px solid transparent; border-right:28px solid transparent; }

/* 关键点：平行四边形与菱形靠 transform */
.parallelogram { width:120px; height:60px; transform:skewX(-20deg); }
.diamond       { width:64px;  height:64px; transform:rotate(45deg); }

/* 关键点：心形 = 一个盒子 + 两个伪元素半圆，各自旋转 45° 咬合 */
.heart { position:relative; width:90px; height:82px; }
.heart::before, .heart::after {
  content:""; position:absolute; top:0; width:45px; height:72px;
  background:#c8401f; border-radius:45px 45px 0 0;
  transform:rotate(-45deg); transform-origin:0 100%; }
.heart::after { left:45px; transform:rotate(45deg); transform-origin:100% 100%; }

/* 关键点：对话泡 = 圆角矩形 + 伪元素三角形尾巴 */
.bubble { position:relative; padding:12px 16px; background:#1c1b18;
  color:#fff; border-radius:12px; }
.bubble::after { content:""; position:absolute; left:20px; bottom:-13px;
  border-left:8px solid transparent; border-right:8px solid transparent;
  border-top:13px solid #1c1b18; }
