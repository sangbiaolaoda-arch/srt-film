零依赖手绘图表

这个片段演示什么：用一个 10 行的 scaleLinear 把数据坐标映射成屏幕坐标，手绘折线 / 柱状 / 饼图（纯 SVG，不引任何图表库）；再演示「线条生长」和「柱子生长」两种入场动画怎么实现。

① 折线图 + 线条生长

用 stroke-dashoffset 从「整条路径长度」动画到 0，视觉上就是线在生长。给 path 加 pathLength="1" 就不用调 getTotalLength()。

② 柱状图 + 柱子生长

柱子用 scaleY(0) → scaleY(1)，变形原点在底部；配合 --i 做依次登场。柱状图必须从 0 起，不能截断 y 轴。

③ 饼图 / 甜甜圈

一条扇区 path 四段：外弧（sweep=1）→ 侧边 → 内弧（sweep=0）→ 闭合。整圆（Δθ=2π）时单段弧会失效，要拆两段；这里 4 片都小于半圈，安全。

核心代码 
// —— 10 行 scaleLinear：数据域 → 屏幕值域。值域写反序就自动翻转 y ——
function scaleLinear(domain, range) {
  const [d0, d1] = domain, [r0, r1] = range;
  const k = (r1 - r0) / (d1 - d0);
  const f = (v) => r0 + (v - d0) * k;      // 数据 → 屏幕
  f.invert = (p) => d0 + (p - r0) / k;     // 屏幕 → 数据（做 hover 时要用）
  return f;
}

// 柱状图的分类轴：算出每格起点与带宽
function scaleBand(domain, range, pi = 0.3, po = 0.3) {
  const n = domain.length, [s, e] = range;
  const step = (e - s) / Math.max(1, n - pi + po * 2);
  const bw = step * (1 - pi);
  const idx = new Map(domain.map((d, i) => [d, i]));
  const f = (d) => s + step * po + step * idx.get(d);
  f.bandwidth = bw;
  return f;
}
