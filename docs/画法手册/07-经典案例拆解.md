## 案例 01 · 交互式机械图（来源：Ciechanowski《Gears》）[抓到·原理／补充·实现]

**它做对了什么**：把整幅工程图压缩成"一个状态变量 + 一个纯函数"，滑块与动画只改状态，图形的每一根线都由同一个几何模型实时重算。

**技术构成**
- **SVG**：承载全部几何（圆、直线、path、渐开线），矢量、可缩放、可精确到亚像素；标注线/法线/节圆都用同一坐标系表达。
- **JS**：`requestAnimationFrame` 循环推进时间 `t`，按 `ω`、`t` 算出角度，重写 `transform`/`path d`。
- **DOM**：滑块、暂停按钮、旁注文字。
- **CSS**：排版与配色，不参与几何。
- 抓取文件确认了交互形态（slider 控速、点击暂停、可全局暂停动画）与全部数学；**渲染层实现由本稿补充**。

### 01.1 单一状态 + 纯函数重绘 + rAF 时间轴 [抓到·交互形态／补充·实现]
核心是**状态与图形解耦**：`render(state)` 只描述"给定状态应该长什么样"，时间推进和用户输入都只是改 state。这样暂停/回放/拖动时间轴全部免费获得。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;font:14px system-ui;background:#111;color:#eee}
svg{display:block;margin:20px auto;background:#181818}</style>
<label style="display:block;text-align:center">ω = <span id="v">1.0</span> rad/s</label>
<input id="w" type="range" min="0" max="4" step="0.01" value="1"
       style="display:block;width:320px;margin:8px auto">
<svg width="360" height="360" viewBox="0 0 360 360">
  <g id="disc">
    <circle cx="180" cy="180" r="120" fill="none" stroke="#4af" stroke-width="2"/>
    <line x1="180" y1="180" x2="300" y2="180" stroke="#4af" stroke-width="2"/>
  </g>
</svg>
<script>
const disc = document.getElementById('disc');
const wEl  = document.getElementById('w'), vEl = document.getElementById('v');
let t = 0, last = performance.now();
// 纯函数：给定状态 -> 图形（不含时间逻辑）
function render(state){
  disc.setAttribute('transform', `rotate(${state.angle} 180 180)`);
}
function frame(now){
  const dt = (now - last) / 1000; last = now;
  t += dt * Number(wEl.value);                 // 只推进状态
  render({ angle: t * 180 / Math.PI });        // 状态 -> 图形
  vEl.textContent = Number(wEl.value).toFixed(2);
  requestAnimationFrame(frame);
}
requestAnimationFrame(frame);
</script>
```

**什么时候能复用**：任何"参数连续可变 + 图形需精确重算"的场景——工程图/几何演示/教学可视化/物理示意。滑块改状态、暂停即停止推进 `t`，时间轴回放自然成立。

### 01.2 渐开线齿形的参数化生成 [抓到·原理／补充·方程与 SVG]
抓到的正文明确：齿廓用**渐开线（involute）**——把绳子绕在基圆上、绷直拉开的端点轨迹；曲线上任一点的**法线始终与基圆相切**，因此满足啮合定律（法线恒过节圆点）。渐开线的参数方程（基圆半径 `rb`，参数 `u`）：

```
x = rb·(cos u + u·sin u)
y = rb·(sin u − u·cos u)
```

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#111}svg{display:block;margin:0 auto}</style>
<svg width="400" height="400" viewBox="-200 -200 400 400">
  <circle r="80" fill="none" stroke="#555" stroke-dasharray="4 4"/>
  <path id="inv" fill="none" stroke="#4af" stroke-width="2"/>
</svg>
<script>
const rb = 80;
function involute(rb, u){                 // 渐开线参数方程
  return [ rb*(Math.cos(u) + u*Math.sin(u)),
           rb*(Math.sin(u) - u*Math.cos(u)) ];
}
let d = '';
for (let u = 0; u <= 2.0; u += 0.02){
  const [x, y] = involute(rb, u);
  d += (d ? 'L' : 'M') + x.toFixed(2) + ' ' + y.toFixed(2);
}
document.getElementById('inv').setAttribute('d', d);
</script>
```

**什么时候能复用**：任何"数学曲线"可视化——凸轮/摆线/李萨如/贝塞尔求导。把参数方程换成目标曲线，其余结构不动。工程图里要的不是"像齿轮"，而是"由方程定义的齿轮"。

### 01.3 用 transform 做旋转 + 齿数比即比例系数 [抓到·公式／补充·实现]
抓到的正文给出：`ω_out = ω_in · N_in / N_out`、`T_out = T_in · N_out / N_in`，啮合两轮转向相反。落到代码上，**别重算每个点的坐标**，用 SVG `transform` 绕轴心旋转；传动关系只是一个乘上去的比例常数。

```html

  font:13px system-ui;color:#ccc;text-align:center}</style>

<svg width="520" height="300" viewBox="0 0 520 300">

    <line x1="140" y1="150" x2="210" y2="150" stroke="#fc6" stroke-width="2"/></g>
  <g id="g2"><circle cx="350" cy="150" r="140" fill="none" stroke="#6f8" stroke-width="2"/>
    <line x1="350" y1="150" x2="490" y2="150" stroke="#6f8" stroke-width="2"/></g>
</svg>
<script>
const g1 = document.getElementById('g1'), g2 = document.getElementById('g2');

const N1 = 12, N2 = 24;
let t = 0, last = performance.now();
function frame(now){
  const dt = (now - last) / 1000; last = now;

  const a1 = t * 180 / Math.PI;

</script>
```

**什么时候能复用**：一切"整体运动"都用 transform（旋转/缩放/平移），别手动重算坐标。联动的传动/级联关系 = 一个比例系数，多级就乘起来（抓到的三齿轮结论：中间惰轮齿数不影响总比）。

### 01.4 滚动作为时间轴（同源迁移）[补充]
Ciechanowski 原文用的是**滑块 + 可暂停动画**，不是滚动；但把同一个状态变量接到 `scrollY` 上，就能得到"滚动即时间轴"的变体——图形固定在视口，文字滚过去分幕推进。

```html
<!doctype html><meta charset="utf-8">
<style>
body{margin:0;background:#111;color:#ccc;font:14px system-ui}
svg{position:fixed;top:50%;left:50%;transform:translate(-50%,-50%)}
p{position:relative;max-width:320px;margin:100vh auto;padding:12px;
  background:#0008;border-left:2px solid #4af}
</style>
<svg width="220" height="220" viewBox="-110 -110 220 220">
  <g id="rot">
    <circle r="60" fill="none" stroke="#4af"/>
    <rect x="-60" y="-8" width="120" height="16" fill="#4af"/>
  </g>
</svg>
<p>滚动 = 时间轴。图形固定，文字滚动切分幕。</p>
<p>第二幕：同一个状态推进到不同阶段。</p>
<p>第三幕。</p>
<script>
const rot = document.getElementById('rot');
function update(){
  const max = document.body.scrollHeight - innerHeight;
  const p = max ? scrollY / max : 0;          // 0..1 归一化滚动进度
  rot.setAttribute('transform', `rotate(${p * 720} 0 0)`);
}
addEventListener('scroll', update, {passive:true}); update();
</script>
```

**什么时候能复用**：长文解说、教程、landing page 的分幕叙事——把 `scrollY` 映射成动画进度，而不是绑真实时间，用户就能"自己控制节奏"。

## 案例 02 · 可见性多边形 / 视野阴影（来源：Red Blob《2D Visibility》）[抓到·算法／补充·实现]

**它做对了什么**：不做全角度扫描，只在**墙的端点角度**投射线，再把命中点按极角排序连成多边形——用最少的射线得到精确视域。

**技术构成**
- **Canvas 2D**：画墙、填充视域多边形、用 `globalCompositeOperation` 做半透明遮罩与减法合成。
- **JS**：射线–线段求交、极角排序、最近命中筛选。
- **DOM**：拖动中心点、滑块。
- 抓到的正文给了算法骨架（下）；可运行实现为补充。

抓到的算法原样：射线只在"墙开始或结束的角度"投射；或更高效地**扫过整圈**，维护一条扫描线穿过的墙表，只留最近的那面墙可见，最近墙一变化就填一个三角形；连线时要用扫描射线去截断当前墙。加法算法从空开始加可见区，减法算法从全可见减去阴影。

### 02.1 射线–线段求交（核心原语）[抓到·原理／补充·实现]
视域算法的一切都建立在这个求交上。用叉积解线性方程，得到的 `t`（沿射线距离）与 `u`（沿线段的 0..1 参数）一次算清。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#111}canvas{display:block}</style>
<canvas id="c" width="500" height="360"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
const walls = [
  [[80,60],[420,60]], [[420,60],[420,300]],
  [[420,300],[80,300]], [[80,300],[80,60]],
  [[200,120],[300,240]]                    // 内部一块障碍
];
const O = [250,180];
// 射线 O+t*d 与线段 A->B 求交；t>0 且 0<=u<=1 才算命中
function raySeg(O, d, A, B){
  const ex = B[0]-A[0], ey = B[1]-A[1];
  const den = d[0]*ey - d[1]*ex;            // r × e
  if (Math.abs(den) < 1e-9) return null;    // 平行
  const qpx = A[0]-O[0], qpy = A[1]-O[1];   // A - O
  const t = (qpx*ey - qpy*ex) / den;        // 沿射线的距离
  const u = (qpx*d[1] - qpy*d[0]) / den;    // 沿线段的参数
  if (t <= 0 || u < 0 || u > 1) return null;
  return [O[0]+d[0]*t, O[1]+d[1]*t, t];
}
// 只在墙端点角度投射（±ε 微偏，处理射线正好擦过端点的情况）
const pts = walls.flat();
const poly = [];
for (const p of pts){
  const ang = Math.atan2(p[1]-O[1], p[0]-O[0]);
  let best = null;
  for (const e of [-1e-4, 0, 1e-4]){
    const d = [Math.cos(ang+e), Math.sin(ang+e)];
    for (const [A,B] of walls){
      const hit = raySeg(O, d, A, B);
      if (hit && (!best || hit[2] < best[2])) best = hit;   // 取最近
    }
  }
  if (best) poly.push([best[0], best[1], ang]);
}
poly.sort((a,b) => a[2] - b[2]);            // 极角排序
// 绘制
g.fillStyle = '#181818'; g.fillRect(0,0,cv.width,cv.height);
g.beginPath(); g.moveTo(O[0],O[1]);
for (const p of poly) g.lineTo(p[0], p[1]);
g.closePath(); g.fillStyle = '#0af8'; g.fill();
g.strokeStyle = '#fff'; g.lineWidth = 2;
for (const [A,B] of walls){ g.beginPath(); g.moveTo(...A); g.lineTo(...B); g.stroke(); }
g.fillStyle = '#f60'; g.beginPath(); g.arc(O[0],O[1],4,0,7); g.fill();
</script>
```

**什么时候能复用**：潜行/roguelike 视野、手电筒光照、安全摄像头覆盖、AI 掩体判定。凡是"从这个点能看到/照亮哪些区域"的问题，都是它。

### 02.2 端点 ±ε 微偏 + 极角排序 [抓到·算法要点／补充·可视化]
抓到正文的伪代码核心是：`endpoints` 按角度排序、用 `open` 表维护扫描线穿过的墙、每到一个端点就判断"最近墙是否改变"。这份可视化把"按极角绕圈扫描"的过程画出来——**排序是算法正确性的前提**。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#111}canvas{display:block}</style>
<canvas id="c" width="420" height="320"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
const walls = [[[90,70],[200,150]],[[340,60],[260,180]],
               [[120,250],[320,260]],[[300,220],[360,120]]];
const O = [210,160];
// 收集所有墙端点，按相对中心的极角排序
const pts = [];
walls.forEach(w => w.forEach(p => pts.push({p})));
pts.sort((a,b) =>
  Math.atan2(a.p[1]-O[1], a.p[0]-O[0]) -
  Math.atan2(b.p[1]-O[1], b.p[0]-O[0]));
let k = 0;
function tick(){
  g.fillStyle = '#141414'; g.fillRect(0,0,420,320);
  g.strokeStyle = '#666'; g.lineWidth = 2;
  for (const [a,b] of walls){ g.beginPath(); g.moveTo(...a); g.lineTo(...b); g.stroke(); }
  g.fillStyle = '#f60'; g.beginPath(); g.arc(O[0],O[1],4,0,7); g.fill();
  for (let i = 0; i <= k && i < pts.length; i++){
    const a = Math.atan2(pts[i].p[1]-O[1], pts[i].p[0]-O[0]);
    g.strokeStyle = (i === k) ? '#4af' : '#4af3';
    g.beginPath(); g.moveTo(O[0],O[1]);
    g.lineTo(O[0]+Math.cos(a)*400, O[1]+Math.sin(a)*400); g.stroke();
    g.fillStyle = '#fff'; g.beginPath(); g.arc(...pts[i].p, 3, 0, 7); g.fill();
  }
  k = (k >= pts.length) ? 0 : k + 1;      // 循环演示扫描
  setTimeout(tick, 120);
}
tick();
</script>
```

**什么时候能复用**：任何"极坐标扫描/角度排序"问题——视域、雷达、扇形命中检测、按方位排序的标注布点。`±ε` 微偏是处理共线/擦边不稳定命中时最省事的兜底。

### 02.3 半透明遮罩抠视野（destination-out）[抓到·思路／补充·实现]
抓到正文提到：用集合运算组合输出，位图层面即合成操作（AND=乘、OR=加并截断）。最常用的落地就是"整个画面盖一层黑，把视野区抠掉"——战争迷雾/聚光灯的标准做法。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#111}canvas{display:block}</style>
<canvas id="c" width="420" height="300"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
// 假视域多边形（真实项目里换成 02.1 算出来的 poly）
const poly = [[210,150],[330,90],[360,150],[330,220],[210,260],[120,230],[90,150],[120,80]];
function scene(){
  g.fillStyle = '#234'; g.fillRect(0,0,420,300);
  g.fillStyle = '#4a6'; for (let i=0;i<40;i++) g.fillRect(i*11,250,8,50);
  g.fillStyle = '#2a4'; g.fillRect(180,120,60,60);
}
function draw(ox, oy){
  scene();
  // 1) 全屏盖一层黑
  g.fillStyle = 'rgba(0,0,0,0.85)'; g.fillRect(0,0,420,300);
  // 2) 把视域多边形从黑层里"抠掉"
  g.save();
  g.globalCompositeOperation = 'destination-out';
  g.beginPath(); g.moveTo(ox,oy);
  for (const p of poly) g.lineTo(p[0],p[1]);
  g.closePath(); g.fill();
  g.restore();
  // 3) 再叠一层暖光表示被看到
  g.save();
  g.globalCompositeOperation = 'lighter';
  g.beginPath(); g.moveTo(ox,oy);
  for (const p of poly) g.lineTo(p[0],p[1]);
  g.closePath(); g.fillStyle = 'rgba(255,180,80,0.18)'; g.fill();
  g.restore();
}
cv.onmousemove = e => {
  const r = cv.getBoundingClientRect();
  draw(e.clientX - r.left, e.clientY - r.top);
};
draw(210,150);
</script>
```

**什么时候能复用**：黑暗地图、战争迷雾、聚光灯、任何"只亮一块"的效果——把所有亮区当成一张被抠掉的蒙版，比逐像素判断便宜得多。

### 02.4 视野与锥形/圆形取交（手电筒、距离衰减）[抓到·思路／补充·实现]
抓到正文点明：把视域输出与圆/渐变圆/锥做交，就能得到"半径限制""距离衰减""手电筒"。这里用受限射线的锥形 + 径向渐变一次做完。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#111}canvas{display:block}</style>
<canvas id="c" width="460" height="320"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
const O = [230,160], dir = -Math.PI/2, FOV = 0.6, RANGE = 170;
const solid = [[[60,220],[400,220]], [[200,80],[200,220]]];
g.fillStyle = '#181818'; g.fillRect(0,0,460,320);
g.lineWidth = 8; g.strokeStyle = '#333';
for (const [[ax,ay],[bx,by]] of solid){ g.beginPath(); g.moveTo(ax,ay); g.lineTo(bx,by); g.stroke(); }
// 在 [-FOV/2, +FOV/2] 内均匀投射线 -> 锥形可见区
const N = 140, poly = [];
for (let i = 0; i <= N; i++){
  const a = dir - FOV/2 + FOV*i/N;
  const d = [Math.cos(a), Math.sin(a)];
  let t = RANGE;
  for (const [[ax,ay],[bx,by]] of solid){
    const ex = bx-ax, ey = by-ay;
    const den = d[0]*ey - d[1]*ex;
    if (Math.abs(den) < 1e-9) continue;
    const qpx = ax-O[0], qpy = ay-O[1];
    const tt = (qpx*ey - qpy*ex) / den;
    const uu = (qpx*d[1] - qpy*d[0]) / den;
    if (tt > 0 && uu >= 0 && uu <= 1) t = Math.min(t, tt);
  }
  poly.push([O[0]+d[0]*t, O[1]+d[1]*t]);
}
g.beginPath(); g.moveTo(O[0],O[1]);
for (const p of poly) g.lineTo(p[0],p[1]);
g.closePath();
const grd = g.createRadialGradient(O[0],O[1],0, O[0],O[1],RANGE);
grd.addColorStop(0, 'rgba(255,220,120,0.55)');
grd.addColorStop(1, 'rgba(255,220,120,0)');       // 距离衰减
g.fillStyle = grd; g.fill();
</script>
```

### 03.3 状态切换要"形变过去"，不要跳变 [补充]
选年份/选地区/hover 高亮时，别重新画一版；用**通用补间**把数值数组动画到目标数组。真实项目里这是 `d3.transition` 的职责，这里给出无依赖版。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#0e1116;color:#eee;font:14px system-ui;text-align:center}
button{margin:8px}</style>
<svg width="360" height="240" viewBox="0 0 360 240"></svg>

<script>
const s = document.querySelector('svg');
const A = [120,60,150,90,180], B = [40,190,80,200,60];
const N = A.length, W = 360, H = 240, bw = W/N - 16;
const rects = [];
for (let i = 0; i < N; i++){
  const r = document.createElementNS('http://www.w3.org/2000/svg','rect');
  r.setAttribute('width', bw); r.setAttribute('x', i*(bw+16)+8);
  r.setAttribute('fill','#4af'); r.setAttribute('y', H); r.setAttribute('height', 0);
  s.appendChild(r); rects.push(r);
}
// 通用补间：把当前高度动画到目标高度
let from = rects.map(()=>0), to = A.slice(), t0 = performance.now(), dur = 600;
function tween(target){
  from = rects.map(r => +r.getAttribute('height'));
  to = target; t0 = performance.now(); requestAnimationFrame(step);
}
function step(now){
  const k = Math.min(1, (now - t0)/dur);
  const e = k < .5 ? 2*k*k : 1 - Math.pow(-2*k+2, 2)/2;   // easeInOutQuad
  for (let i = 0; i < N; i++){
    const h = from[i] + (to[i] - from[i]) * e;
    rects[i].setAttribute('height', h);
    rects[i].setAttribute('y', H - h);
  }
  if (k < 1) requestAnimationFrame(step);
}
document.getElementById('a').onclick = () => tween(A);
document.getElementById('b').onclick = () => tween(B);
tween(A);
</script>
```

### 03.4 同一份数据、两套布局（mobile vs desktop）[补充·对应抓到的题材]
抓到的列表页里有一篇正题为"Techniques for Data Visualization on both Mobile & Desktop"。落地做法：用 `matchMedia` 切布局，同一组数据，窄屏改成横向柱/简化标注，而不是把大图等比缩小到字看不清。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;font:14px system-ui;background:#fff}
svg{display:block;margin:20px auto;max-width:100%}</style>
<svg id="chart" width="600" height="300" viewBox="0 0 600 300"></svg>
<script>
const svg  = document.getElementById('chart');
const data = [3,7,4,9,6,8];
function render(){
  const horiz = !matchMedia('(max-width:600px)').matches;   // 宽屏竖柱，窄屏横柱
  const W = 600, H = 300, n = data.length, max = Math.max(...data);
  let html = '';
  if (horiz){
    const gap = W/n;
    html = data.map((v,i) => {
      const h = (v/max)*(H-40);
      return `<rect x="${i*gap+8}" y="${H-h-20}" width="${gap-16}"
              height="${h}" fill="#457b9d"/>`;
    }).join('');
  } else {
    const gap = H/n;
    html = data.map((v,i) => {
      const w = (v/max)*(W-40);
      return `<rect x="20" y="${i*gap+8}" width="${w}"
              height="${gap-16}" fill="#457b9d"/>`;
    }).join('');
  }
  svg.innerHTML = html;
}
render();
matchMedia('(max-width:600px)').addEventListener('change', render);
</script>
```

**什么时候能复用**：任何图表上线前都要面对手机——用同一份数据切布局（换朝向、砍标注、合并小类），而不是缩放大图把字挤成一片。

## 案例 04 · WebGL 全屏效果（来源：Codrops 风格）[补充·全部]

**说明**：抓到的 Codrops 文件只是**教程分类列表页**（标题＋摘要＋链接）。标题本身点明了技法分布：鼠标跟随方形透镜 + RGB 偏移、liquid glass 折射、datamosh、自定义光标拖尾（Three.js/TSL）等，但**代码抓取文件里没有**。以下为补充，用**原生 WebGL（零依赖）**写最小版。

**它做对了什么**：一个覆盖全屏的三角形 + 一个 fragment shader，把"逐像素的效果"全交给 GPU；鼠标/时间只作为 uniform 喂进去。

**技术构成**
- **WebGL**：一个全屏三角（比两个三角的 quad 少一个顶点、少一条接缝），顶点着色器只做透传。
- **GLSL**：所有效果在 fragment 里逐像素算（位移/涟漪/色差/噪声）。
- **JS**：每帧写 uniform（`u_time`、`u_mouse`、`u_res`），`requestAnimationFrame` 驱动。
- **DOM/CSS**：只负责让 canvas 铺满。

约定：鼠标 y 用 `clientY` 是自上而下的，而 WebGL 的 `gl_FragCoord` / 纹理 v 轴自下而上，所以要 `1 - y/H` 翻转。

### 04.1 全屏三角 + 基础 uniform（时间/分辨率/鼠标）[补充]
最小可跑骨架：屏幕坐标归一化、鼠标位置的涟漪位移、cos 调色盘上色。全屏三角的坐标是 `(-1,-1),(3,-1),(-1,3)`，超出裁剪区也没关系。

```html
<!doctype html><meta charset="utf-8">
<style>html,body{margin:0;height:100%;overflow:hidden}
canvas{display:block;width:100%;height:100%}</style>
<canvas id="c"></canvas>
<script>
const cv = document.getElementById('c'), gl = cv.getContext('webgl');
function resize(){ cv.width = innerWidth; cv.height = innerHeight;
  gl.viewport(0,0,cv.width,cv.height); }
addEventListener('resize', resize); resize();
const VS = `attribute vec2 p; void main(){ gl_Position = vec4(p,0.,1.); }`;
const FS = `
precision highp float;
uniform vec2 u_res; uniform float u_time; uniform vec2 u_mouse;
void main(){
  vec2 uv = gl_FragCoord.xy / u_res;      // 0..1，y 向上
  vec2 m  = u_mouse / u_res;              // 鼠标也在同样的 y 向上坐标
  float d = distance(uv, m);
  float ripple = sin(d*40.0 - u_time*4.0) * 0.02 * exp(-d*6.0);
  uv += normalize(uv - m + 1e-5) * ripple;
  vec3 col = 0.5 + 0.5*cos(u_time + uv.xyx*6.0 + vec3(0.0,2.0,4.0));
  col *= smoothstep(1.2, 0.0, d)*0.9 + 0.15;   // 鼠标附近更亮
  gl_FragColor = vec4(col,1.0);
}`;
function sh(t,src){ const s = gl.createShader(t); gl.shaderSource(s,src);
  gl.compileShader(s);
  if (!gl.getShaderParameter(s, gl.COMPILE_STATUS)) console.error(gl.getShaderInfoLog(s));
  return s; }
const prog = gl.createProgram();
gl.attachShader(prog, sh(gl.VERTEX_SHADER,   VS));
gl.attachShader(prog, sh(gl.FRAGMENT_SHADER, FS));
gl.linkProgram(prog); gl.useProgram(prog);
const buf = gl.createBuffer(); gl.bindBuffer(gl.ARRAY_BUFFER, buf);
gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1,-1, 3,-1, -1,3]), gl.STATIC_DRAW);
const loc = gl.getAttribLocation(prog,'p');
gl.enableVertexAttribArray(loc); gl.vertexAttribPointer(loc,2,gl.FLOAT,false,0,0);
const uRes = gl.getUniformLocation(prog,'u_res'),
      uTime= gl.getUniformLocation(prog,'u_time'),
      uM   = gl.getUniformLocation(prog,'u_mouse');
let mx = innerWidth/2, my = innerHeight/2;
addEventListener('mousemove', e => { mx = e.clientX; my = innerHeight - e.clientY; });
const t0 = performance.now();
(function loop(now){
  gl.uniform2f(uRes, cv.width, cv.height);
  gl.uniform1f(uTime, (now-t0)/1000);
  gl.uniform2f(uM, mx, my);
  gl.drawArrays(gl.TRIANGLES, 0, 3);
  requestAnimationFrame(loop);
})(t0);
</script>
```

**什么时候能复用**：hero 背景、鼠标跟随高光、页面过渡遮罩，以及所有"把一个滤镜铺满屏幕"的场合。骨架搭好后，改 FS 就能换效果。

### 04.3 方形镜头 + RGB 偏移（对应抓到的标题）[抓到·选题／补充·GLSL]
抓到的 Codrops 标题里有"Mouse-Following Square Lens Effect … image distortion, RGB shifting"。核心：用**矩形 SDF** 做一个"只在方块内生效"的掩码，色差只在窗口内打开。

```html
</script>
```

**什么时候能复用**：鼠标跟随的放大镜/取景框、局部故障风（RGB 分离）、任何"只在某块区域启用重效果"的交互。矩形 SDF 换成圆形就是圆形镜头，换两次 SDF 相减就是描边。

### 04.4 时间驱动的噪声/液态流动（无交互也生动）[补充]
没有鼠标时画面不能死。用 value noise + fbm（5 个八度叠加）在 fragment 里造流场，效果全部由 `u_time` 驱动。这是"程序化液态/烟雾/极光"的通用配方。

```html
<!doctype html><meta charset="utf-8">
<style>html,body{margin:0;height:100%;overflow:hidden}canvas{display:block;width:100%;height:100%}</style>
<canvas id="c"></canvas>
<script>
const cv = document.getElementById('c'), gl = cv.getContext('webgl');
function rs(){ cv.width = innerWidth; cv.height = innerHeight; gl.viewport(0,0,cv.width,cv.height); }
addEventListener('resize', rs); rs();
const VS = `attribute vec2 p; void main(){ gl_Position = vec4(p,0.,1.); }`;
const FS = `
precision highp float; uniform vec2 u_res; uniform float u_time;
float hash(vec2 p){ return fract(sin(dot(p, vec2(127.1,311.7))) * 43758.5453); }
float noise(vec2 p){
  vec2 i = floor(p), f = fract(p);
  f = f*f*(3.0 - 2.0*f);
  float a = hash(i),            b = hash(i+vec2(1.0,0.0)),
        c = hash(i+vec2(0.0,1.0)), d = hash(i+vec2(1.0,1.0));
  return mix(mix(a,b,f.x), mix(c,d,f.x), f.y);
}
float fbm(vec2 p){
  float s = 0.0, a = 0.5;
  for (int i = 0; i < 5; i++){ s += a*noise(p); p *= 2.03; a *= 0.5; }
  return s;
}
void main(){
  vec2 uv = gl_FragCoord.xy / u_res.y;                 // 用高度归一，避免拉伸
  vec2 q = vec2(fbm(uv + u_time*0.08), fbm(uv + 5.2 - u_time*0.06));
  float v = fbm(uv + 2.0*q + u_time*0.05);
  vec3 col = mix(vec3(0.03,0.05,0.12), vec3(0.95,0.55,0.25), v);
  col = mix(col, vec3(0.2,0.7,0.9), smoothstep(0.6,0.9,v)*0.5);
  gl_FragColor = vec4(col,1.0);
}`;
function s(k,src){ const h = gl.createShader(k); gl.shaderSource(h,src); gl.compileShader(h);
  if (!gl.getShaderParameter(h, gl.COMPILE_STATUS)) console.error(gl.getShaderInfoLog(h));
  return h; }
const pr = gl.createProgram();
gl.attachShader(pr, s(gl.VERTEX_SHADER, VS));
gl.attachShader(pr, s(gl.FRAGMENT_SHADER, FS));
gl.linkProgram(pr); gl.useProgram(pr);
const b = gl.createBuffer(); gl.bindBuffer(gl.ARRAY_BUFFER, b);
gl.bufferData(gl.ARRAY_BUFFER, new Float32Array([-1,-1,3,-1,-1,3]), gl.STATIC_DRAW);
const a = gl.getAttribLocation(pr,'p');
gl.enableVertexAttribArray(a); gl.vertexAttribPointer(a,2,gl.FLOAT,false,0,0);
const uRes = gl.getUniformLocation(pr,'u_res'), uT = gl.getUniformLocation(pr,'u_time');
const t0 = performance.now();
(function loop(now){ gl.uniform2f(uRes, cv.width, cv.height);
  gl.uniform1f(uT, (now-t0)/1000); gl.drawArrays(gl.TRIANGLES,0,3);
  requestAnimationFrame(loop); })(t0);
</script>
```

**什么时候能复用**：hero 背景、加载态、音乐可视化的底噪、任何"需要持续变化但不想做逐帧贴图"的场合。噪声流场的参数（频率、速度、配色）一套配方能衍生出几十种画面。

## 案例 05 · CSS 前沿效果 [补充·全部]

### 05.2 景深视差（perspective + translateZ）[补充]
多层放在同一 `perspective` 场景里，越靠前（`translateZ` 越大）跟随鼠标位移越大，自然产生视差与空间感。

```html

<style>

       overflow:hidden;background:radial-gradient(#1b2a4a,#070b14)}
.layer{position:absolute;inset:-20%;display:grid;place-items:center;
       font:bold 8rem system-ui;transition:transform .2s ease-out}
.a{color:#3a5}.b{color:#58a}.c{color:#cdf}
</style>
<div class="scene" id="scene">
  <div class="layer a">远</div>
  <div class="layer b">中</div>
  <div class="layer c">近</div>
</div>
<script>
const scene = document.getElementById('scene');
const zs = [-300, -150, 0], scales = [1.6, 1.3, 1];

  const x = (e.clientX/innerWidth  - .5);
  const y = (e.clientY/innerHeight - .5);
  scene.querySelectorAll('.layer').forEach((l, i) => {
    const depth = (i+1) * 14;                     // 越近位移越大
```

**什么时候能复用**：hero 分层视差、鼠标跟随的空间感、产品拆解图、任何"要纵深"的场景。

### 05.3 position: sticky 驱动的进度条 [补充]
顶栏用 `sticky` 钉住，内部进度条宽度绑定滚动百分比。`sticky` 本身不需要 JS，进度条只需要一次 `scroll` 映射。


**什么时候能复用**：长文阅读进度、步骤引导（sticky 步骤条）、时间线、文档站侧边目录高亮。

### 05.4 原生 scroll-driven animations（滚动即时间轴，零 JS）[补充]
现代浏览器已支持把滚动进度直接当 CSS 动画的时间轴：`animation-timeline: scroll(root)`。不合规/老浏览器用 JS 兜底。

```html
<!doctype html><meta charset="utf-8">
<style>
body{margin:0;font:16px/1.7 system-ui;background:#0e1116;color:#ddd}
#track{height:400vh}
#box{position:fixed;top:50%;left:8%;width:80px;height:80px;
     background:#0af;border-radius:14px}
@supports (animation-timeline: scroll()){
  #box{ animation: slide linear both; animation-timeline: scroll(root); }
}
@keyframes slide{ to{ left:80%; transform:rotate(360deg); } }
</style>
<div id="box"></div><div id="track"></div>
<script>
/* 兜底：不支持 scroll() 的浏览器用 JS 映射滚动进度 */
if (!CSS.supports('animation-timeline: scroll()')){
  const box = document.getElementById('box');
  addEventListener('scroll', () => {
    const p = scrollY / (document.body.scrollHeight - innerHeight);
    box.style.left = (8 + p*72) + '%';
    box.style.transform = `rotate(${p*360}deg)`;
  }, {passive:true});
}
</script>
```

**什么时候能复用**：用 CSS 声明式做滚动动画（进度、视差、逐字浮现），省掉 scroll 监听与节流，主线程更轻。上线时保留 JS 兜底即可。

## 案例 06 · 生成艺术 / 粒子系统 [补充·全部]

**说明**：本案例在抓取的 4 个文件里**没有直接来源**（Ciechanowski 的是机械图，Red Blob 的是算法，另两个是列表页）。以下为补充。

**它做对了什么**：用"确定性随机"保证可复现，用"噪声流场"给运动以组织，用"半透明矩形覆盖"一句话实现轨迹淡出。

**技术构成**：**Canvas 2D** 为主（逐点/逐粒子绘制、`fillRect` 覆盖做余晖）；噪声与 PRNG 用纯 JS（零依赖）。

### 06.1 确定性随机（seeded PRNG）[补充]
同一个种子 → 同一幅画。刷新页面布局不变、能分享"种子"，这是生成艺术的基本素养。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#0e1116}canvas{display:block}</style>
<canvas id="c" width="480" height="320"></canvas>
<script>
const g = document.getElementById('c').getContext('2d');
// 确定性伪随机（mulberry32）：同种子 -> 同序列
function mulberry32(seed){
  return function(){
    seed |= 0; seed = seed + 0x6D2B79F5 | 0;
    let t = Math.imul(seed ^ seed >>> 15, 1 | seed);
    t = t + Math.imul(t ^ t >>> 7, 61 | t) ^ t;
    return ((t ^ t >>> 14) >>> 0) / 4294967296;
  };
}
const rnd = mulberry32(20261013);   // 换种子 -> 换作品；不换 -> 稳定复现
g.fillStyle = '#0e1116'; g.fillRect(0,0,480,320);
for (let i = 0; i < 400; i++){
  const x = rnd()*480, y = rnd()*320, r = 1 + rnd()*4;
  g.fillStyle = `hsl(${180 + rnd()*120} 80% ${40 + rnd()*30}%)`;
  g.beginPath(); g.arc(x, y, r, 0, 7); g.fill();
}
</script>
```

**什么时候能复用**：生成艺术可复现、程序化纹理、随机但可分享的关卡/布局、测试用稳定假数据。凡是"要随机但不想每次都不一样"的场合。

### 06.2 噪声流场（value noise + fbm）[补充]
用哈希 + 双线性插值做 value noise（确定性、无需库），5 个八度叠成 fbm；粒子的运动方向取自场的角度，就能得到"有组织又不可预测"的流线。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#0e1116}canvas{display:block}</style>
<canvas id="c" width="480" height="320"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
function hash(x, y){
  const s = Math.sin(x*127.1 + y*311.7) * 43758.5453;
  return s - Math.floor(s);
}
function noise(x, y){                     // value noise（确定性）
  const xi = Math.floor(x), yi = Math.floor(y);
  const xf = x - xi, yf = y - yi;
  const u = xf*xf*(3-2*xf), v = yf*yf*(3-2*yf);
  const a = hash(xi,yi),   b = hash(xi+1,yi),
        c = hash(xi,yi+1), d = hash(xi+1,yi+1);
  return (a*(1-u) + b*u)*(1-v) + (c*(1-u) + d*u)*v;
}
g.fillStyle = '#0e1116'; g.fillRect(0,0,cv.width,cv.height);
g.lineWidth = 1;
for (let k = 0; k < 300; k++){
  let x = Math.random()*cv.width, y = Math.random()*cv.height;
  g.strokeStyle = `hsla(${190 + k%80} 70% 60% / .5)`;
  g.beginPath(); g.moveTo(x, y);
  for (let s = 0; s < 120; s++){
    const a = noise(x*0.004, y*0.004) * Math.PI * 2;   // 场角度
    x += Math.cos(a)*2; y += Math.sin(a)*2;
    g.lineTo(x, y);
  }
  g.stroke();
}
</script>
```

**什么时候能复用**：流线图、背景织物、地形/云层高度图、粒子场的速度场。噪声是"随机"和"结构"之间的旋钮，调频率就有完全不同气质。

### 06.3 粒子轨迹淡出（半透明矩形覆盖）[补充]
经典技巧：**不要每帧 clear**，而是盖一层 `rgba(0,0,0,0.06)` 的矩形——旧轨迹自然衰减成拖尾。一行代码替代逐个擦除。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#000;overflow:hidden}canvas{display:block}</style>
<canvas id="c" width="480" height="320"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
const parts = Array.from({length:160}, () => ({
  x: Math.random()*cv.width,  y: Math.random()*cv.height,
  vx: 0, vy: 0, h: Math.random()*360
}));
g.fillStyle = '#000'; g.fillRect(0,0,cv.width,cv.height);
function hash(x, y){ const s = Math.sin(x*127.1 + y*311.7) * 43758.5453; return s - Math.floor(s); }
function noise(x, y){
  const xi = Math.floor(x), yi = Math.floor(y), xf = x-xi, yf = y-yi;
  const u = xf*xf*(3-2*xf), v = yf*yf*(3-2*yf);
  const a = hash(xi,yi), b = hash(xi+1,yi), c = hash(xi,yi+1), d = hash(xi+1,yi+1);
  return (a*(1-u)+b*u)*(1-v) + (c*(1-u)+d*u)*v;
}
function frame(){
  // 关键：不 clear，盖一层极淡的黑 —— 旧轨迹自然衰减
  g.fillStyle = 'rgba(0,0,0,0.06)';
  g.fillRect(0,0,cv.width,cv.height);
  for (const p of parts){
    const a = noise(p.x*0.005, p.y*0.005) * Math.PI * 2;
    p.vx = p.vx*0.9 + Math.cos(a)*0.25;
    p.vy = p.vy*0.9 + Math.sin(a)*0.25;
    p.x += p.vx*3; p.y += p.vy*3;
    if (p.x < 0) p.x += cv.width;  if (p.x > cv.width)  p.x -= cv.width;
    if (p.y < 0) p.y += cv.height; if (p.y > cv.height) p.y -= cv.height;
    g.fillStyle = `hsl(${(p.h += 0.5) % 360} 80% 60%)`;
    g.fillRect(p.x, p.y, 1.4, 1.4);
  }
  requestAnimationFrame(frame);
}
frame();
</script>
```

**什么时候能复用**：粒子拖尾、鼠标绘制、音频可视化、示波器余晖、弹幕/星轨。`alpha` 越小拖尾越长，是一个可以直接调的"记忆长度"。

### 06.4 黄金角螺旋排布（index 驱动的确定性构图）[补充]
不需要随机数：用黄金角 `≈137.5°` 和面积均匀的半径分布，就能得到向日葵式的、不结块的确定性排布。

```html
<!doctype html><meta charset="utf-8">
<style>body{margin:0;background:#0e1116}canvas{display:block}</style>
<canvas id="c" width="440" height="440"></canvas>
<script>
const cv = document.getElementById('c'), g = cv.getContext('2d');
const N = 900, GA = Math.PI * (3 - Math.sqrt(5));   // 黄金角 ≈ 137.5°
g.fillStyle = '#0e1116'; g.fillRect(0,0,440,440);
for (let i = 0; i < N; i++){
  const r = Math.sqrt(i/N) * 200;                   // 令点面密度均匀
  const a = i * GA;
  const x = 220 + Math.cos(a)*r, y = 220 + Math.sin(a)*r;
  const t = i/N;
  g.fillStyle = `hsl(${200 + t*160} 85% ${35 + t*35}%)`;
  g.beginPath(); g.arc(x, y, 1 + t*3.5, 0, 7); g.fill();
}
</script>
```

**什么时候能复用**：种子点排布（叶序/向日葵/粒子盘）、不留白的确定性构图、UI 里"随机感"却不凌乱的装饰（光点、角标、雷达布点）。
