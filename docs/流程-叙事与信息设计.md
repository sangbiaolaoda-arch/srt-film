# 流程 · 叙事与信息设计

> 这份文档补的是 srt-film 唯一空缺的一层。
> 现有门禁管「这一拍做得对不对」；这里管「**这一拍该不该这么讲**」。
>
> 姊妹篇：`docs/流程-确定性动画与逐帧验收.md`（管渲染与验收的工程侧）。

---

## 0. 为什么需要这一层

现有四道门禁各自回答一个问题：

| 门禁 | 回答 |
|---|---|
| G8 排版合规 | 字够不够大、对比度够不够、强调有没有滥用 |
| G9 时间线契约 | 动效时长在不在窗口内、能不能复现 |
| G10 关系唯一 | 每对元素关系的「结构+运动」签名是不是唯一 |
| G11 图表自洽 | 图上的数字能不能溯源、几何成不成比例 |

它们全都在回答「**做出来对不对**」。但有个更早的问题没人问：

> 这一拍为什么要这样讲？把它整段删掉，观众的理解会不会受损？

336 套版式可以全部合规、全部可溯源、全部门禁绿，成片依然会像一组 PPT ——
因为「像不像 PPT」不由任何单拍决定，而由**拍与拍之间的信息关系**决定。

本文件的条目分两类，逐条标注：

- **`[可判定]`** —— 能落成机器检查。已实现的写清在哪，未实现的写清怎么加。
- **`[需人看]`** —— 只能靠判断，但给一句具体的自问，避免退化成"感觉不对"。

来源是一份外部的《HTML 科普视频制作流程学习手册》。只收其中**可验证**的部分，
清单式与口号式的条目不收；收进来的都改写成能对着 `Beat` / `Layout` / `Slot` 落地的形式。

## 1. 事实与视觉隐喻必须分开记账

科普片最容易出的错不是画面丑，是**画面炫但结论不准**。根因是把视觉隐喻当成了事实本身：
用弹簧解释能量谷，观众就记住了"系统里真的有一根弹簧"。

每一拍除了 `text`，还要能回答四个问题：

| 字段 | 回答什么 | 例（"接触涉及电磁相互作用"这一拍） |
|---|---|---|
| `claim` | 这一拍要表达的**事实** | 宏观接触对应电磁相互作用 |
| `visual_metaphor` | 用什么画面让观众理解 | 两组电子云靠近，中间出现排斥区 |
| `accuracy_note` | 这个隐喻会不会误导 | 不把电子画成沿固定轨道运行的小球 |
| `on_screen_text` | 屏幕上必须读到的字 | "接触不是实体互相穿入" |

**`[可判定]`** 三件事：

1. 四个字段是否齐全 —— 缺 `accuracy_note` 的拍直接标红。
2. `accuracy_note` 是否与 `visual_metaphor` 雷同 —— 抄一遍等于没想（做相似度比对即可）。
3. **每个断言能否溯源**：`claim` 一旦包含数字，必须能对上 `content.numbers`。
   对不上就说明这个数字是编的 —— 这条与 `trace.ts` 的 `extractNumbers` 天然衔接。

**`[需人看]`** 隐喻到底会不会误导。要问具体的问题：
"一个没学过物理的人看完这一拍，会不会记住一个错的机制？"

> **落地位置**：`Beat` 旁挂一个可选的 `design` 附注（`claim` / `visual_metaphor` /
> `accuracy_note` / `on_screen_text`），由导演覆写层（`overrides.ts`）提供，
> **不进自动规划路径** —— 自动规划不应该生成科学断言。

## 2. 镜头表必须写「不许出现什么」

只写"要什么"的镜头表，执行时会把所有可选的东西都塞进去。加一个 `forbidden` 字段，
把禁区写进合同，比事后删更省事。

```
must_read:  ["原子尺度", "示意，非真实拍摄"]
forbidden:  ["无解释的旋转", "让文字盖住主图", "把示意图画得像实拍"]
```

**`[可判定]`** `forbidden` 非空是最低要求（空着就是没想过）。
更实的判定是**把它变成检查项** —— 例如写了"文字盖住主图"，
就应该有对应的一行断言；写了不检查等于没写。

**`[需人看]`** 禁区列得对不对。

## 3. 一个运动值不值得存在：六个问题

给任何一个动效（`slot.m` / `slot.mx`）问这六个问题，答不全的就是装饰：

1. **目的** —— 揭示、比较、追踪、放大、聚合，还是转场？
2. **主体** —— 哪个元素真的在变？
3. **驱动** —— 为什么**在这个时刻**开始动？（上一步完成了？数值越过阈值了？）
4. **方向** —— 从哪来？沿视线、沿力/信号路径、沿尺度轴，还是奔下一拍构图？
5. **节奏** —— 何时加速、何时减速、何时停？
6. **落点** —— 动完之后，画面里留下了什么新状态？

**`[可判定]`** 第 2 与第 6 条可判：

- 第 2 条 = 该槽在动效前后的几何/样式是否真的变了
  （`qa-frames` 的**结构差 Δ** 已经在做像素级版本，见姊妹篇 §4）。
- 第 6 条 = 动效结束时是否引入了新元素或新状态。
  若动效跑完画面与开始时**语义等价**，这个动效就是空转。

**`[需人看]`** 第 1、3、4、5 条 —— 尤其是"为什么在这个时刻开始动"。

## 4. 运动之间的关系：六种

单个动效合格不代表整场成立。画面里同时有五个动效各动各的，比只有一个动效更糟。
值得建立的六种关系：

| 关系 | 含义 | 例 |
|---|---|---|
| **父子** | 主图移动，附属元素跟随 | 标签引线跟着目标走；被放大的区域动，标尺同步变 |
| **因果** | A 变了 B 才响应 | 数值越阈值，警戒区才出现；连接点建立后，光点才通过 |
| **对比** | A 与 B 同时间轴、同坐标尺度、同基线 | 两个方案用同一比例尺展开，差异才可信 |
| **继承** | 上一拍的元素成为下一拍的起点 | 上一拍的一个圆、一条线、一个位置 |
| **对位** | 上一拍的元素变成下一拍的另一种角色 | A 的圆形开口变成 B 的观察窗；A 的运动终点 = B 的主体中心 |
| **对比停顿** | 重要结论出现时，辅助运动暂时停住 | 给读取留时间 —— 这是节奏，不是动画漏做 |

**`[可判定]`** 这是目前**最值得补的一块**。`Layout` 现在只有 `enter`（入场池）和
`emphasis`（强调），缺"这一拍的主运动"与"谁跟随谁"：

```ts
interface Layout {
  // ……现有字段……
  /** 主运动：整场唯一，决定这一拍在讲什么 */
  main?: { kind: "reveal" | "grow" | "approach" | "draw" | "pan"; slot?: string };
  /** 次运动：跟随某个槽（父子/因果关系） */
  follow?: { slot: string; of: string }[];
  /** 对比停顿的位置（拍内 0..1），此区间内辅助运动应静止 */
  pauseAt?: number;
}
```

有了字段就能判：

- **主运动存在** —— 拍内最大结构差 > 阈值（`qa-frames` 已实现）。
- **继承 / 对位** —— G10 已有「结构+运动」双签名，可扩展成**跨拍签名**：
  相邻两拍之间是否至少存在一对元素共享几何锚点（位置 / 尺寸 / 颜色 token 连续）。
  若相邻拍之间一个共享锚点都没有，就是硬切 —— **硬切不是错，但必须显式声明**，
  不能是"因为两段代码分开写了"。
- **对比停顿** —— 拍内应该出现一段 Δ 接近 0 的区间（`qa-frames` 的 Δ 序列可直接读出）。

**`[需人看]`** 关系用得对不对。

## 5. 镜间连续性：六种传递

相邻两拍至少要传递一种连续性，否则观感就是"切页"：

**形状** 圆变成下一拍的圆形观察窗 ·
**位置** 上一拍的主体中心成为下一拍的构图中心 ·
**方向** 上一拍向右运动，下一拍继续向右（或有理由地反向）·
**颜色** 同一个物理量沿用同一个颜色 token ·
**结构** 上一拍主图的局部放大，直接成为下一拍的完整结构 ·
**概念** 上一拍提的问题，下一拍立刻给证据，不跳去无关背景。

**`[可判定]`** 前五种都能对照 `Slot.box` / `tone` 做几何与颜色比对（同 §4 的跨拍签名）。
第六种不可判定，但要保证**每处硬切都有说明**。

**`[需人看]`** 连续性是否让人感到"同一个世界延续下去"。

> **硬切的正确用法**：明确的时间跳跃、实验对比、结论重击、从假设切到证据。
> 硬切后必须**立刻**建立新焦点 —— 不能让观众花一秒找主体。
> 每个硬切都该能回答："为什么这里必须断开？"

## 6. 反 PPT 检查表

逐拍对着问，八条：

- [ ] 主体是否真的发生了**能改变理解**的变化，而不只是淡入？ **`[可判定]`** 结构差 Δ
- [ ] 文字与图形是否彼此解释？ **`[需人看]`**
- [ ] 是否存在可追踪的主运动？ **`[可判定]`** `layout.main` 存在 + Δ
- [ ] 至少一个元素是否从前一拍继承，或为下一拍留线索？ **`[可判定]`** 跨拍锚点
- [ ] 是否存在不服务于内容的装饰？有则删除。 **`[需人看]`**
- [ ] 读完文字之后，画面是否还展示了**一层新信息**？ **`[需人看]`**
- [ ] 主图停下来时，停顿是否有阅读或理解上的必要？ **`[需人看]`**
- [ ] **这一镜能否被直接替换成普通标题页而不损失任何信息？** **`[可判定]`**

最后一条是整份文档里最有价值的一问。拿掉全部动画，信息一点没损失，说明动画只是包装。
它的机器版本就是：**拍内主结构从头到尾没变过** ——

```
场内最大结构差 Δ < 阈值  →  这一拍可以整段换成标题页
```

这条已经在 `tools/qa-frames.mjs` 里实现了（`--per-scene` / `--motion-min` /
`--fail-on-still`）。实测校准见姊妹篇 §4。

## 7. 炫技的两个清单

**高价值炫技**（这些同时是信息动作）：

尺度连续变化（参照物与标尺同步变）· 图形变形（一个结构变成另一种有意义的结构）·
信息同步（数值/标尺/曲线/标注响应同一个变化）· 空间追踪（镜头围绕目标推进，
目标与标签始终可读）· 高密度信息的有序揭示（轮廓 → 结构 → 标签 → 结论逐层展开）·
概念回环（结尾与开场相似，但理解变了）· 绘制过程与真实状态一致（曲线真的按数据长出来）。

**低效炫技**（删掉不会变差，所以应该删掉）：

随机粒子到处飞 · 所有东西都发光 · 无意义的 HUD 小数字和**假数据** ·
全屏抖动旋转闪屏 · 频繁缩放却不改变信息 · 不断切换配色字体镜头语言 ·
把 3D 当默认方案 · 每个元素都同时淡入滑入缩放。

**`[可判定]`** 其中两条可以查：

1. **假数据** —— 屏幕上出现的每个数字都要能溯源到 `content.numbers`（G11 已在做）。
   任何"按进度切档但无依据"的读数都算假数据。
2. **无谓的持续运动** —— 画面里长期存在与信息无关的运动层（背景粒子、扫描线），
   会让 Δ 检测的**信噪比变差**。判据：把该层关掉后 Δ 是否仍能反映真实结构变化。

**`[需人看]`** 其余 —— 一句话判据："把它删掉，信息、悬念或节奏会不会变差？"

## 8. 时长与节奏

- **每拍只允许一个主运动、一个最强焦点。** 需要切焦点时用运动或对比度引导视线过去。
- **复杂画面必须包含相对安静的阶段** —— 每秒都最大刺激，等于没有刺激。
- 转场时长参考：微小元素切换 0.15–0.35s · 常规场景转换 0.35–0.75s ·
  有空间推进感 0.6–1.2s · 重大揭示可更快切入，但要给结果留读取时间。
- **时长由信息量决定，不由秒数平均切片。** 判断标准是"读完关键文本并理解画面需要多久"。

**`[可判定]`** 转场时长落 G9 的窗口检查（已有）。拍内 Δ 序列的形状可读出
"有没有安静段"与"停顿位置是否合理"。

**`[需人看]`** 节奏是否舒服。

## 9. 落地清单：srt-film 现在缺什么

按性价比排序。前两项直接影响成片质感，建议先做。

| # | 缺什么 | 怎么补 | 判定方式 |
|---|---|---|---|
| 1 | `Layout` 没有「主运动」概念 | 加 `main` / `follow` / `pauseAt` 三个字段（见 §4） | 拍内 Δ > 阈值 |
| 2 | 拍与拍之间没有继承机制 | 跨拍共享几何锚点 + 硬切显式声明 | 跨拍签名比对 |
| 3 | 没有事实/隐喻记账 | `Beat.design` 附注（导演覆写，不进自动规划） | 字段完整 + 数字溯源 |
| 4 | 没有 `forbidden` 字段 | 镜头表加禁区，写成检查项 | 非空 + 有对应断言 |
| 5 | 没有反 PPT 门禁 | 已实现为 `qa:frames --fail-on-still` | 见 §6 最后一条 |
| 6 | 版式的"安静段"没被利用 | 在 `pauseAt` 区间冻结辅助动效 | Δ 序列出现低谷 |
