## 一、图表映射：什么数据关系，配什么图表

来源：**FT Visual Vocabulary**（Financial Times 视觉新闻团队，业界选择图表的标准语法）。
核心思想：先判断旁白里的**数据关系属于哪一类**，再从该类里挑图表 —— 而不是先想「画个饼图」。

| 关系 | 判断特征 | 首选图表 | 备选 |
|---|---|---|---|
| **Deviation 偏离** | 相对参考点的正负（盈亏、温差） | Diverging bar | diverging stacked bar、surplus/deficit line |
| **Correlation 相关** | 两变量联动（收入×寿命） | Scatterplot | line+column、bubble、XY heatmap |
| **Ranking 排名** | 位次比绝对值重要 | Ordered bar | slope、lollipop、dot strip plot |
| **Distribution 分布** | 值的出现频率与形状 | Histogram | boxplot、violin、population pyramid |
| **Change over Time 时间变化** | 趋势随时间演变 | Line | column、area、slope、fan chart（预测） |
| **Part-to-whole 构成** | 整体拆成部分 | Stacked column | pie、donut、treemap、venn |
| **Magnitude 大小** | 比大小 | Column / Bar | paired bars、**Isotype（象形图）**、lollipop、radar |
| **Spatial 空间** | 地理位置为主角 | Choropleth | flow map、dot density、cartogram |
| **Flow 流动** | 状态间的量/强度迁移 | Sankey | waterfall、chord、network |

共 9 类关系、67 种图表。FT 特别标注的陷阱：相关 ≠ 因果（除非明说，读者会当因果）。

**对 srt-film 的意义**：`needs` 门禁（无数字不出图表）依然成立 —— 但现在**概念图形**
的选择可以借这套关系学：旁白说「损失比收益陡」= deviation + magnitude 关系 →
价值函数曲线（fig-scurve）就是正确的图；「风险与心动一起归零」= deviation →
对向衰减柱（fig-dim）。图表不是随机的形状，是关系的正确拼写。

## 二、图像映射：语义 → 视觉隐喻

来源：视觉隐喻设计研究（圣加仑大学 Eppler 的 4F 检验、视觉叙事教程、概念插画设计原则）。

### 2.1 选隐喻的 4F 检验（Eppler）

1. **Fit 贴合** —— 隐喻必须贴合这句话本身的逻辑，不能是通用装饰
2. **Familiar 熟悉** —— 用人人共享的经验（岔路=选择、走廊=无尽、天平=权衡）
3. **Fresh 新鲜** —— 在「熟悉的边缘」上取一点新意，陈词滥调（灯泡=创意）不如不用
4. **Facilitate 促进理解** —— 隐喻要帮观众更快理解，而不是更费解

### 2.2 设计原则（跨源汇总）

| 原则 | 一句话 | 例子 |
|---|---|---|
| 相关性 | 图形必须从这句话推导出来 | 「不下注的赌局」→ 准星锁定 |
| 清晰性 | 一眼看懂，不需要解释 | 收据 = 你付出过的凭证 |
| 尺度传义 | 用大小表达强弱 | 小人 vs 纸塔 = 压垮 |
| 运动显义 | 动画让隐喻更明确 | 撞上止损闸的箭头 = 边界 |
| **一景一喻** | 单画面禁止混合隐喻 | 天平拍里不再塞第二组几何 |
| 共享经验 | 人人都走过的路才作数 | 迷宫=困惑、门=退路 |

### 2.3 隐喻词典（srt-film 已实现 16 个，按此标准扩充）

| 旁白语义 | 图形 | 隐喻逻辑 |
|---|---|---|
| 越靠近越疼 | fig-curve-pain | 距离→痛感的陡峭衰减曲线 |
| 二选一的设问 | fig-fork / fig-question | 岔路 / 悬在两端之间的问号 |
| 两难 | fig-balance | 天平两盘高低差 = 权衡 |
| 一套规则 | fig-checklist | 逐项勾选 = 被执行的清单 |
| 没有尽头 | fig-corridor | 透视走廊 = 走不到头的重复 |
| 代价与收益同灭 | fig-dim | 对向衰减柱 = 同源同灭 |
| 损失比收益陡 | fig-scurve | 前景理论价值函数（学理正确） |
| 同额不同权 | fig-weigh-bars | 丢 100 的柱远高于捡 100 |
| 同一源头 | fig-converge | 两线汇聚一点 |
| 结算 | fig-receipt | 你在乎过的收据 |
| 从未疼过 | fig-flatline | 平线 vs 起伏虚线对照 |
| 退路 | fig-door | 墙 + 敞开的门缝透光 |
| 价格 vs 底线 | fig-clash | 箭头撞上止损闸 |
| 没有答案的设问 | fig-question | 问号悬在分叉轴上 |
| 走到了头 | fig-path-end | 透视路收束到尽头的门 |
| 被引述的设问 | fig-quote-frame | 成对引号 + 空的引用框 |

**扩充规则**：新图形必须先过 4F，再写进词典 —— 没有旁白句子能指出它对应哪一句，
就不许画（与「不允许无数据画图表」同一条诚实约束）。

## 三、排版映射：画面排版法则

来源：Butterick《Practical Typography》关键规则 + Canva 视觉层级六法则。

### 3.1 硬规则（Butterick，直接对照 srt-film 参数）

| 规则 | 业界标准 | srt-film 现状 | 判定 |
|---|---|---|---|
| 正文字号 | 网页 15–25px | caption/label 13–18px | ✓ |
| 行距 | 字号的 120–145% | `lineH = size × 1.32` | ✓（132%） |
| 行长 | 45–90 字符 | headline 槽宽 ≤ 16 全角字 | ✓（更紧，海报语境合理） |
| 粗体慎用 | 尽量少、粗斜不同用 | 只有语义强调词 800 | ✓ |
| 居中慎用 | 少用 | statement 系仍以 start/end 为主 | ✓ |
| 全大写加字距 | +5–12% | kicker/badge `letterSpacing: 2` | ✓ |

### 3.2 视觉层级六法则（Canva）→ srt-film 的落实

1. **Size 尺度** —— 字号阶梯 14→168 共 8 档；一屏只允许一个 mega/huge
2. **Color & Contrast 对比** —— 语义强调 = 换色 + 放大 1.14 + 加粗（三通道同时变）
3. **Typographic Hierarchy 三级字阶** —— 每拍最多：大标题 / 副信息 / 注脚（BEAT 角标）三级
4. **Fonts 字体克制** —— 全片只两族：宋体（标题）+ 黑体（注脚）
5. **Spacing 留白** —— 12×8 网格 + 四角 40px 安全边距 + 装饰层点阵引导
6. **Composition 结构** —— 图形槽与文字槽不重叠（figures x/y 定位修复后成立）
