## 0. 硬约束（多源一致，先于一切用法）

1. 文字是舞台元素，可出现在画面任何稳定区域；每屏当海报设计——观众只该记住**一个**词/短语。
2. 一次只动 **1~2 个元素**，运动之间保留明确静止瞬间。
3. 节奏数值：字符错峰 20-40ms / 词 40-70ms / 行 60-100ms；单段 400-600ms；**总入场 ≤800ms**（超长句改词级或行级）。
4. 入场一律 ease-out（首选 easeOutExpo `cubic-bezier(0.16,1,0.3,1)`），禁 linear。
5. 三种角色每幕必须分清：**Active**（主句，最大字号+主动效）/ **Anchor**（锚定构图）/ **Support**（辅助，更小更淡更静）。
6. 可读性红线：旋转只许 5-15°；glitch 单次 <400ms；逐字入场只用于短句；模糊类一幕 ≤2 个元素；声音关闭也要能看懂。

## A. 布局站位类（文字放哪）

### A1 上下站位让位（quiet recedes）
旧句（Anchor）上移+缩小到 0.6~0.7+透明度降到 0.5 → 新句（Active）从中心进入、字号更大。小而淡=远，制造纵深。适合金句递进、定义展开。

### A2 背景大字层
大号词组压暗到 opacity 0.13~0.15 做远景铺底，前景内容在其上展开。背景比前景**迟 0.2s** 才动。适合章节幕、概念定调。

### A3 三层景深
前景大标题 / 中景副文字 / 背景小字幕；背景 60-70% opacity；同色系微差（深蓝前景+浅蓝背景）。可复制整组缩小压暗秒造纵深副本。适合片头、章节卡。

### A4 对角构图
文字左上 ↔ 道具右下（或反向），视线走对角线，破对称。适合"选择/交易/对比"叙事。

### A5 贴纸盖印
短句落四角，快+easeOutBack 回弹+旋转 5-15°。适合判断句、转折标签（"弃权？""反悔了"）。

## B. 入场语法类（怎么进）

### B1 打字机
逐字 0.2-0.3s/字 + 光标。适合引入句、内心独白、代码/引文。总时长仍受 ≤800ms 约束时用词级替代。

### B2 遮罩滑升（行业标准的标题入场）
每行套 overflow:hidden 盒，文字从基线下方滑升入盒，行间错 60-100ms。多行标题、章节标题卡首选。

### B3 逐字/逐词错峰
fade+rise，字符 20-40ms、词 40-70ms 偏移，形成级联。只用于短句（单词/口号）。

### B4 模糊聚焦
blur 12px→0 + opacity 0→1，镜头对焦感。优雅单句、Logo 定版。GPU 重，一幕 1-2 个。

### B5 定向擦除（clip-path wipe）
字形不动、mask 从一侧擦入；可配等速移动的色条/下划线。编辑感、lower-third、小节标题。

### B6 翻页/3D 翻转
perspective + rotateY(-90°→0)，适合"书/信/卡片/翻面"语义的道具与文字同台入场。

## C. 强调与节奏类（怎么强调）

### C1 词义驱动动效
词是什么样就怎么动：heavy=慢而重落点带停顿 / light=快而微弹 / sharp=干脆无缓动 / quiet=退后淡出 / fall=下坠 / rise=上升。**动效为意义计时，不为运动计时。**

### C2 scale punch 两档
80%→100% + 急促 ease-out = 干脆自信（普通强调）；50%→100% + 缓慢 ease-in = 戏剧化（重磅揭示）。全片固定这两档，不再多。

### C3 快慢对比
紧迫处快闪（词连击、≤0.5s/4词）、分量处慢揭示（长句 2s 向结尾加速）。同片内快慢交替才出节奏。

### C4 数值 pop
数字 count-up + scale pop，标签/单位随后 settle（更小更静）。数据幕专用。

## D. 环境与收束类

### D1 次级动效
主文字动时，背景形状轻微放大、装饰元素反向漂移，场景才"活"。幅度 ≤5%。

### D2 跑马灯纹理
大字横滚 marquee 做装饰层（低对比度），导航/情绪背景用，不承载信息。

### D3 morph 换词
一个词插值变形为另一个（"问题"→"方案"）。概念转换专用，路径不兼容就退化为 mask 交叉淡化。

### D4 波浪/涟漪
字符按 sine 起伏，入场触发一次或持续低幅。活泼/音乐段落。

## E. 色彩强调类（颜色是强调工具，不是装饰，也不是语义标签）

> **用户勘误（2026-10-17，两轮）**：①红 ≠ 危险——红是**最高强调档**，任何最该被记住
> 的内容都可以上红；②**其他颜色同理**——每种颜色都是一个"强调档位/情绪通道"，
> 不绑定某个具体语义。强调的本质是**色 + 重 + 大 + 符号的组合拳**，颜色只负责
> "看哪里、什么情绪"，词义和符号负责"是什么"。

### E1 强调阶梯（先升级再上色，不许跳级）
同一短语按**强调强度**（不是内容含义）选级：
- **L0 中性**：ink 常规字重——陈述，不抢视线；
- **L1 次强调**：琥珀 + 加粗（可 +5~8% 字号）——"注意这里"；
- **L2 最高强调**：红 + 加粗 + 加大（+15~25%），按需 + 符号伴随——"这句话是核心"。
一幕内最多到 L2 一次；全片红只给最该被记住的句子，用多了红就失效（见 E3）。
判断标准不是"这句话是什么"，而是"这句话是不是全场最该记住的"。

### E1b 颜色通道表（其他颜色同理，同一套语法）
| 颜色 | 强调角色 | 典型用例 | 搭配符号 |
|---|---|---|---|
| 红 | 最高强调档 | 核心结论、危险、损失 | 禁止⊘ / 下箭头 |
| 琥珀 | 次强调档 | 注意、转折、关键词 | 感叹 / 星标 |
| 绿 | 正面强调通道 | 放心、收益、正确做法 | 对勾✓ / 上箭头 |
| 蓝 | 信息强调通道 | 冷知识、补充说明、数据来源 | i 圆点 |
| 灰/muted | 退后层 | 注脚、次要信息 | — |

通用语法不变：**加粗 + 加大 + 符号伴随 + 盖印/定向入场**适用于任何颜色；
换颜色只换"通道"，不换动效语法。

### E2 符号伴随（词 + 图标 = 双通道编码）
L2 强调词旁配语义一致的图标（"危险"→禁止符号⊘，"损失"→下箭头，"得到"→上箭头，
"正确"→对勾✓，"注意"→感叹号，"冷知识"→i 圆点）。
符号是**可选加强件**：不是每个强调词都要配图标，配了就必须语义一致。
图标入场同样有语义：禁止符号用**盖印**（快+回弹+微旋转），
箭头用**定向滑入**（往哪指往哪滑）。图标与文字间距 ≈ 0.3em，图标尺寸 ≈ 字号 × 0.9。

### E3 稀缺性契约（稀缺性维持信号强度）
最高档强调必须稀缺——观众每次看到红，都知道"这是重点"。红用多了等于没红（习惯化）。
同理琥珀/绿/蓝各自守自己的档位，不混用。静态饱和色会疲劳，落地后允许**一次** pulse
（1.06 / 0.3s）重新拉注意力，仅此一次。

### E4 变色时机 = 转折点
动画进行中变色（黑→红/琥珀随 scale）标记"消息的转折点"，比提前变色更有力——
色彩变化本身就是一个节拍。

### E5 灰度自检
导出代表帧转灰度：层级还成立，构图才是真的稳；依赖颜色撑层级 = 白搭。

## F. SVG 语义映射类（看到词就知道画什么图）

> 2026-10-17 学自用户："我说'危险'，你就知道画一个红色禁止符号；换一个场景呢，要能推出来。"
> 查证来源：隐喻三层级方法论、图标语法（名词/动词/形容词）、CHI'20 3S 框架、
> 视觉隐喻映射库、反隐喻清单。核心方法论一句话：
> **"这个概念定住在一瞬间，它长什么样？"——答案通常就是该画的图。**

### F1 隐喻三层级（选符号的优先顺序，认知摩擦从低到高）
1. **直接隐喻**：形状与对象物理形态一致——"钱"画硬币、"杯子"画杯子。优先用；
2. **间接隐喻**：用对象的属性或关联工具——"交易"画握手、"估价"画天平、"风险"画走钢丝；
3. **抽象符号**：约定俗成的几何——"禁止"画红圈斜杠、"信息"画 i。仅在 1/2 都不好画时用。
推演口诀：先问"它本身长什么样？"→ 再问"它发生时用什么工具/伴随什么？"→ 最后才用约定符号。

### F2 概念→符号映射表（片子常用域，持续扩充）
| 概念域 | 首选符号 | 备选符号 | 入场动效 |
|---|---|---|---|
| 危险/禁止 | 红圈斜杠⊘ | 警示三角! | 盖印（快+回弹+微旋转） |
| 损失/下降 | 下箭头↓ | 碎裂、硬币漏口袋、融化的冰块 | 定向滑入（往下） |
| 得到/上升 | 上箭头↑ | 礼物盒、硬币落袋、上升阶梯 | 定向滑入（往上） |
| 公平/权衡 | 天平 | VS、跷跷板 | 左右摆动后停稳 |
| 拥有/归属 | 手持物 | 名字标签、绳系着 | 从画面外递入 |
| 交易/交换 | 双向箭头⇄ | 握手、钱币换物 | 两物相向滑入 |
| 犹豫/未知 | 问号? | 虚线路径分叉 | 摇摆入场 |
| 确定/完成 | 对勾✓（实心） | 盖章"成交" | 单笔画出（stroke draw） |
| 时间/紧迫 | 沙漏⏳ | 时钟、倒计时 | 翻转或指针转动 |
| 记忆/过去 | 泛黄旧照片 | 怀旧滤镜、倒放 | 淡入+轻微泛黄 |
| 心理/内心 | 头脑轮廓 | 心形、thought bubble | 从头顶浮出 |
| 风险/不稳定 | 走钢丝的人 | 跷跷板上的球、悬空积木 | 轻微摇晃循环 |
| 规则/约束 | 围栏/虚线框 | 锁🔒、笼子 | 从四周合拢 |
| 释放/自由 | 断开的锁链 | 打开的笼门、飞出 | 弹开（反向合拢） |

### F3 图标语法（组合规则：名词 + 动词 + 形容词）
- **名词**（画什么）：主体物的简化形——越简单越通用；
- **动词**（怎么变含义）：箭头=方向指令，**红圈斜杠=最强动词"否定"**（盖在任何名词上就反转含义）；
- **形容词**（语境修饰）：底色块给语境（蓝底=信息、红底=警示），实心=确定/完成，线性=进行中/未定。
组合示例：名词"香烟"+动词"红圈斜杠"="禁止吸烟"；名词"天平"+形容词"倾斜"="不公平"。

### F4 语义唯一性（一个符号一个含义，防语义漂移）
同一片子里，一个符号只允许对应一个核心概念——"星标"全片只表示"重点"，
就不许在别处表示"评分"。符号复用=含义稀释，观众要重新学习。

### F5 空间语义（位置本身携带含义，画之前先想站位）
- **上 = 多/涨/好/未来，下 = 少/跌/坏/过去**（损失的东西往下掉，得到的从上来）；
- **左 = 过去/旧，右 = 未来/新**（时间线从左往右）；
- **大 = 重要/近，小淡 = 次要/远**（与 A1 让位法则同源）；
- **中心 = 结论，边缘 = 补充**（最重要的句子站中间）。
3S 框架印证：元素的**空间关系本身有语义**（手放在房子下方=房屋保险），
组合两个符号时先想清楚谁上谁下、谁左谁右。

### F6 风格一致（符号必须长在同一个视觉家庭里）
线宽统一（片内组件 3px 描边）、圆角一致、配色走 E1b 通道表、抽象层级一致
（不要一个写实一个火柴人）。单个符号的精美不重要，整组符号的"视觉重力"均衡才重要。

### F7 反隐喻清单（AI 味廉价符号，用了显廉价）
齿轮=整合、拼图=团队合作、灯泡=灵感（已疲劳）、握手=合作（无独特性时）、
火箭=发布、隧道尽头的光=解决方案、冰山=隐藏复杂度、蓝紫网格=科技。
替代思路：同一个概念找**新的一瞬**——"灵感"不画灯泡，画"雾散开露出路"；
"成长"不画火箭，画"种子顶开水泥"。片子自带的道具（杯子/硬币/天平）永远优先。

### F8 概念不在表里时的推演流程（可复制的思考步骤）
1. 这个概念**发生的一瞬间**画面是什么？（定帧测试）
2. 它有**物理载体**吗？有→直接隐喻；没有→它**伴随什么工具/动作**？→间接隐喻；
3. 组合 F3 语法：名词+动词+形容词；
4. 查 F4（没和已有符号撞含义）、F5（站位对不对）、F6（风格同家）、F7（没踩廉价清单）；
5. 选入场动效：符号的**入场方式要和含义同向**（见 F2 末列）。

## G. 图表语义映射类（词语→图表→动画，数据也是修辞）

> 2026-10-17 学自用户："'进步'用一排上升的柱状图+生长入场；那退步呢？比例呢？"
> 查证来源：IPA/Evergreen 选型法、英国 ONS 八关系框架、Cleveland 长度>角度规则、
> Disney 十二原则×数据动画（工程已有 docs/chart-method.md，G 类是它上面的**词语层**）。
> 核心原则：**消息动词决定图表，动画方向携带涨跌信息。**

### G1 消息动词 → 图表选型（先问"这个词在说什么关系"）
听到一个词，先归到八种关系之一，图表自动确定：
| 消息动词 | 数据关系 | 图表 | 出处 |
|---|---|---|---|
| 进步/增长/提升 | 时间趋势（上行） | 柱状系列（离散）或折线（连续） | ONS: time |
| 退步/下滑/流失 | 时间趋势（下行） | 同构图表**反向动画**（见 G3） | |
| 占比/比例/份额 | 部分占整体 | 华夫图/堆叠条/环形（≤4 片才饼） | Cleveland 规则 |
| 对比/谁更大 | 类别比较 | 柱状图/成对柱/天平（2 个时） | ONS: magnitude |
| 转变/前后 | 前后差值 | 前后两态 + 差值箭头 | 对比揭示 |
| 波动/起伏 | 时间趋势（多向） | 折线（只连连续变量） | |
| 权衡/五五开 | 对半比例 | 环形图 50/50 或天平 | |
| 排名/榜首 | 排序 | 降序横向条 | ONS: ranking |

### G2 词语→图表→动画 速查表（片子常用，持续扩充）
| 词语 | 图表 | 入场动画 | 颜色通道 |
|---|---|---|---|
| 进步 | 上升柱状系列 | **生长**：自零基线左→右错峰（0.1-0.16s/根）+过冲回稳 | 绿 |
| 退步 | 同一柱状系列 | **倒放生长**：先满高在場，右→左逐根缩回基线 | 红 + 下箭头 |
| 比例 | 华夫图（10/100 格） | **逐格点亮**（错峰 pop），重点格子最后压轴 | 中性+重点格强调色 |
| 比例（单片独大） | 环形图 | 自 12 点钟**顺时针扫掠**，最大片先 | 重点片强调色 |
| 翻倍/减半 | 大数字卡 | count-up（seek 安全用双文本交叉淡化） | 语义色 |
| 对比 | 成对柱/天平 | 矮柱先立、高柱后长（慢一拍制造张力） | 两通道各一色 |
| 转变 | 前后两态 | 旧态让位（A1）→ 新态接管 + Δ 标签 | 灰→强调色 |

### G3 动画方向 = 数值方向（动画本身携带涨跌信息）
- **涨 = 从基线向上生长**；**跌 = 倒放**（从满到缩）或自上而下压出——
  同一张图表，动画方向反了语义就反了；
- 折线**只能从左往右描画**（时间方向），跌势靠线下行的形状表达，不许倒着描；
- 比例从**12 点钟顺时针扫**（钟表约定）或逐格点亮；
- "生长"（grow-up）这个词本身留给积极语义——退步不配用生长，用倒放。

### G4 感知规则（为什么这样选：人眼比长度准，比角度/面积不准）
- 比较 → 柱（长度）优于饼（角度）：Cleveland 规则；
- 饼图双门槛：≤4 片 且 最大片 ≥25%，否则改华夫/堆叠条；
- 柱状图基线必须从 0 起（截断=视觉欺骗）；折线 y 轴可以裁剪；
- 华夫图的优势：观众可以**数格子**——"7/10"比 70% 的角更快被读出。

### G5 一图一消息
一张图只回答一个问题；标题写**结论**不写数据名（"放弃的人多了一倍"✓，
"图 3：两种情况对比"✗）。观众 5 秒内读不出结论 = 图表选错或太复杂。

### G6 与 F 类的衔接
词语里带**具体实物**（钱/杯子/天平）走 F 类画符号；带**数量关系**（更多/一半/翻倍/趋势）
走 G 类画图表；两者常同台：符号当主角、图表当证据（或反过来），入场遵守"一次只动 1-2 个元素"。

## 落地到 endowment 管线

- storyboard 每幕加 `typo` 字段：`{role:[Active/Anchor/Support], pos, entrance, emphasis, params}`，cue 对齐；
- 时间轴全部时间函数求值（seg/ease+t），seek-safe 不用 tween（管线既定约定）；
- 入场 easing 统一封装 `easeOutExpo`，punch 两档封装 `punchSnap` / `punchDrama`；
- 改动验收：只渲**典型案例片段**（5-8s 局部），不整片重渲；本地看，不动 GitHub。
