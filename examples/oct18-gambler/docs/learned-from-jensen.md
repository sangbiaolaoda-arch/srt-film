## 二、值得学、等下一支片再用的

1. **「判据要直接对准会出的错」**——delay_audit 从 v1（延迟 ≤45%，误伤 23/35 幕）修到 v2（中点可见度，1/35 幕）的教训。我们任何新门禁立项时先问：这个指标是不是「错误本身」，还是「错误的代理变量」。已写进 conventions。
2. **0.5px 级的误报豁免清单**（同坐标 opacity 交替、上层底板遮盖、动态 transform 读不到按 0 算）——verify 报 issue 后先对照豁免清单再改代码，避免修不存在的 bug。
3. **精确抽帧复核**：联络表格子可疑时用 `ffmpeg -i out.mp4 -ss <t>`（-ss 放 -i 后）复核，别信关键帧附近的缩略图。本次排黑帧时已用到同思路。
4. **环境故障对照实验**：拿旧入口跑一帧，判断是稿子坏了还是环境坏了。我们的对应版：verify-v2 页面就绪 ✗ 时先用 node 直接 import 各模块定位语法错（本次 s14 缺逗号即此法抓到）。
