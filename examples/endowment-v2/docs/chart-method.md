# 图表选型与图表动画方法论（chart-method）

> 沉淀于 2026-10-17。来源：OpenMontage data-visualization skill（决策树+时序表）、
> Disney 十二原则×数据可视化（lobehub/agentskills 同源技能）、Remotion 图表动画范式、
> clicdata / snappycharts / graphmake 选型指南。实现载体：`src/charts.js`。

## 一、选型决策树（先选对图，再谈动画）

按顺序问，命中即停：

| 数据情况 | 用什么 |
| --- | --- |
| 没有数据 / 单个数字 | **大数字卡（stat card）**，不要用图表（1-2 个数据点的图是空图） |
| 3-9 个数据点，比较各类别数量 | **柱状图**（标签长用横向；排名用降序横向条） |
| 前后对比 / 变化 | **成对柱状图** 或 stat card + 差值箭头 |
| 时间趋势 | **折线图**（强调总量用面积图）；禁止用折线连离散类别 |
| 部分占整体（比例） | **环形图/饼图**（≤6 片，>6 片聚合"其他"）；单片独大时最有效 |
| 关键指标 KPI | 3-6 张 stat card 网格 |
| 排名 | 降序横向条形 |

硬规则：饼图 >6 片不可读；柱状图 Y 轴必须从 0 起（截断=欺骗）；折线只连连续变量。

## 二、图表动画规范（Disney 十二原则 × 数据）

| 图表 | 入场动画 | 时长参考 |
| --- | --- | --- |
| 柱状图 | 自**零基线**生长，**左→右错峰**（0.1-0.16s/根），back.out **过冲回稳**（squash & stretch） | 单根 0.85s，系列 2-4s |
| 折线图 | **左→右描线**（pathLength=1 + dashoffset 1→0），终点圆点压轴 | 0.6-2.4s |
| 环形/饼图 | 自 **12 点钟顺时针扫掠**，**最大片先**，中心标签最后落 | 每片 0.9s |
| KPI 数字 | count-up（seek 环境用双文本交叉淡化，禁 onUpdate） | 1.5-2s |
| 强调 | outlier 脉冲/描边圈；significant change 才夸张，**不许夸张数据本身** | 0.3-0.5s |

通用纪律：
1. **框架先于数据**：坐标轴/网格先在，数据再进来。
2. **标签随后落定**（labels settle after data）：数值标签在柱顶/点落位后 0.3s 淡入，跟随但不抢戏。
3. **build-up 后必须 hold ≥3s** 供阅读；旁白先走就延长场景或简化图表。
4. **对比揭示**（comparison reveal）：先呈现基线 → 再动画变化 → 最后出 delta 标签。
5. 进场 300-500ms 错峰，更新 200-300ms——比 UI 慢一档，给理解留时间。
6. seek/逐帧导出安全：全部用 attr 补间（height/y/dasharray/dashoffset），**禁止 onUpdate/onStart 回调**。
