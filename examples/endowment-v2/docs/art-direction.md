# 美术总纲（art-direction）· endowment-v2 / v3

> 这轮从「深底图标」升级到「有主体、有空间、有光」的画面。每条规则都附可判定检查，
> 不靠「感觉高级」。取证与前后对比见文末。

## 一、问题证据（改之前）

| 现象 | 证据 |
| --- | --- |
| 主体是图标，不是物 | 人 = 圆 + 梯形 + 两根棍腿（厕所图标）；杯 = 圆角矩形；币 = 圆 + ¥ |
| 没有空间 | 40 幕共用同一张竖向渐变，只换色温与光池位置 → 「十二张都一样」在背景层重演 |
| 主体不落地 | 人物/杯子都浮在渐变里，没有地面、没有接触影 |
| 全片一个色调 | `SCENE_TONE` 只有 cool/warm/neutral 三档，34/40 幕是 cool → 等于没有色彩脚本 |
| 空 | 一帧里只有一个小图标 + 底部字幕胶囊，负空间没有内容可看 |

## 二、五条硬规则

1. **先立空间，再放主体**。每幕先有「地平线 + 地面 + 光池 + 空气」四件套，主体才落地。
2. **主体三值以内**：受光面 / 暗面 / 接触影。第三色只允许是语义色（青=得到、砖红=失去、琥珀=价值），
   不允许为了「好看」再加彩色。
3. **每件物都有落地影**：大而柔的投影 + 小而深的接触影。没有影 = 贴纸。
4. **统一光源（左上）**：左缘一条冷边缘光，右半压暗；高光只出现在左上。
5. **一帧一个焦点**：主焦点是主体（最大/最亮/有影），字层（章节标题 > 标签 > 字幕）不许和它抢。

## 三、色板与空间 token（`src/palette.js`）

三层分工（60-30-10）：

| 层 | token | 用途 |
| --- | --- | --- |
| 60% 底 | `baseTop/baseBottom/floor/wall/haze` | 天地墙 + 空气透视；**按幕换**（`ACTS`） |
| 30% 支撑 | `panel/panelSoft/steel/steelDim/steelDeep/paper/paperShade/paperDark` | 结构、面板、物的本体 |
| 10% 强调 | `accent/accentSoft/accentDeep` + `cool/warn` | 只点价值/价格/关键结论；语义固定 |

光：`rim/rimCool/shadow/glow/glowCool/vignette`。**主体与背景的光从同一组 token 取**，
禁止组件里写死 rgba。

色彩脚本（`ACTS` × `SCENE_ART`）：5 个调色动作 —— cold（开场/设问）、steel（实验/证据）、
ember（损失/失效）、warm（自我反思）、night（收尾）。每幕登记 `act + env`，
不登记就落默认值（cold/void）。**不同段落要拉开真差距**：ember 偏紫红、warm 偏褐金。

## 四、环境系统（`src/backgrounds.js`）

`env` 与 `act` 正交：env 决定结构，act 决定色温。六种环境：

| env | 结构 | 用在哪 |
| --- | --- | --- |
| `hall` | 远景柱列 + 拱门剪影 | 开场、设问、定理 |
| `lab` | 高窗 + 斜光柱 + 长桌 | 康奈尔实验（s10–s15、s25–s26） |
| `campus` | 天空 + 两层柱廊 + 台基 | s09 校园 |
| `grid` | 透视地面网格 | 价格轴、柱状、走势 |
| `room` | 墙 + 右侧窗 + 桌面 | 七天退货、闲鱼、自白 |
| `void` | 只有光池 + 同心弧 + 微尘 | 抽象/数字/情绪幕 |

每张背景固定五层：底色 → 光池 → 结构剪影 → 地面（渐变过渡，不是硬边）+ 地平线雾 + 脚下光池 → 暗角。
微尘用 sceneKey 哈希取位置（确定性，禁 `Math.random`）。

## 五、主体画法（`src/components.js`）

五个步骤，顺序不能反：

1. **剪影先行**：3 秒内能认出是什么（人/杯/币/卡）。细节先不加。
2. **体积**：用两段渐变（受光→背光）代替平涂；杯是圆柱（左亮右暗 + 口沿内壁阴影），
   人是「肩线曲线 + 下摆弧度」（不是梯形）。
3. **接触**：落地影 + 接触影。影的位置 = 物的底缘，不是包围盒中心。
4. **光**：左缘边缘光（`rimCool`），高光只在左上；右上角压暗。
5. **细节只加在识别点上**：杯口椭圆 + 把手内侧暗边；币的内环 + 高光弧；卡片的折角 + 底边压暗。

## 六、构图

- 基线：`STAGE.horizon=440 / ground=472`。站立物的底缘落在 ground 附近（±30px 内），
  否则就是「浮」。悬浮概念物（卡/标签/币）可以离地，但必须有影。
- 非对称优先：主体偏左/偏右，留白给视线方向；只有「对峙 / 二选一」才居中。
- 字层分级：章节标题（顶部 112–198）> 标签胶囊（P=260）> 字幕（底部 660）。
  同一幕不同时出现两个同级文本块（字幕已经说了的话，画面不再重复）。
- 纵深：背景剪影（远）→ 主体（中）→ 字幕（近）；必要时加前景散景（`#blurLg`，不透明度 ≤0.05）。

## 七、可判定检查

| 检查 | 工具 | 门槛 |
| --- | --- | --- |
| 布局碰撞（组×组、主体×字幕带/标题/安全边） | `window.__layoutReport()` | 0 issue |
| 文字出血（所有 `<text>` 在 1280×720 内） | `tools/verify-v2.mjs` | 0 issue |
| 字幕带（整条落在 y 596–706） | `tools/verify-v2.mjs` | 0 issue |
| 确定性（同 t 两次序列化逐字节一致） | `tools/verify-v2.mjs` | same |
| 成片可解码 / 分辨率 / 时长 / 无全黑帧 | `tools/render-cdp.mjs` | 全过 |
| 逐幕目检（主体可辨、有影、有空间） | 接触印相 8×5 | 人看 |

## 八、前后对比（实测）

- 背景环境类型：1 种 → 6 种（`SCENE_ART` 40 幕全部登记）
- 主体：图标（无影、无明暗）→ 三值 + 落地影 + 边缘光（人/杯/币/卡）
- 色彩脚本：3 档色温、34/40 同档 → 5 个调色动作，按叙事段落分配
- 验收：`verify-v2` 4/4 通过；布局碰撞 0；文字出血 0；确定性 same

## 九、来源

- MOTION_PHILOSOPHY（nateherkai/hyperframes-student-kit）：one idea per beat、负空间、
  光是主体、vignette+grain 每帧、调色板 ≤5 色且每色有语义、必须目检。
- color-script（EVZheng-Lab）：全片一层基调 + 每幕做加减法；同一调色动作共用一档；
  不同状态之间落差要真拉开。
- 60-30-10 / Von Restorff：强调色恒定、只给 1–2 个关键元素。
- 本机技能库 `visual-craft`：SVG 确定性渲染、嵌套 svg 必须显式 x/y、渐变 id 带实例前缀。
